# Lemon 错误码与修复指南（v0.4.0）

错误输出为三段式：`错误[错误码] 说明` + `--> 文件:行:列` + `带 ^ 的源码片段`，多数还带 `= 提示`。

**通用流程**：先看错误码定位类别 → 再核对本页的"典型触发" → 按"修复方式"改写。
若代码用到尚未实现的特性，报错属于预期，应改写代码或明确告知用户当前版本不支持。

---

## 条件与逻辑（写 `if` 时的自查清单）

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| `E0318`：`if` 的条件必须是 bool | 把数字/文本当成条件了 | `if a != 0`、`if name != ""`、`if flag` |
| `E0307`：`&&` 的操作数必须是 bool | 两侧写成了比较表达式之外的东西 | `a > 0 && b > 0`，不要写 `a && b` |
| `E0307`：`!` 的操作数必须是 bool | 对数字取反了 | `!(a > 0)` 或直接 `a <= 0` |
| `E0307`：文本不能用 `>` 比较 | 文本没有全序 | 只用 `==` / `!=` |
| `E0202`：`if` 的条件后应紧跟 `{` | 漏了花括号，或把 `==` 写成了 `=` | 补 `{`；比较用 `==` |
| `E0201`：`elif` 必须紧跟在 `if ... 之后` | `elif` / `else` 单独出现 | 写进 `if` 分支链 |
| 分支里的变量外面用不到 | 分支体是独立作用域（与 `try` 一致） | 把声明提到分支外，或在里面直接使用 |

## 词法 E01xx

| 码 | 含义 | 典型触发 | 修复方式 |
| --- | --- | --- | --- |
| `E0102` | 使用了尚未支持的符号 | `7 % 3`、`[1,2]`、单个 `&` 或 `\|`、全角 `（ ） ｛ ｝ ；`、`openUrl(https://example.com)`（网址没加引号） | **算术、比较、逻辑运算符都已支持**。剩下的只有取余 `%`、列表 `[ ]` 与单个 `&` / `\|`（提示会建议改写成 `&&` / `\|\|`）。全角括号/分号会提示改用半角；全角逗号 `，` 与冒号 `：` 不受影响。**`:` 不是语法符号**：网址、时间等含 `:` 的文本必须加引号 |
| `E0103` | 非法数字 | `1.`（小数点后无数字）、`1元`（数字后紧跟字符）、`1min2`（单位后还有字符）、`99999999999999999999`（超出安全整数） | `1.` → `1.0`；`1元` → `"1元"`（加引号）；超大整数改用 `double` 或减小数值。**时间单位只认 `ms` / `s` / `min` / `h`**（大小写不限），且后面不能再跟字母数字 |
| `E0104` | 字符串未闭合 | `say("你好)` | 补上配对的 `"`。若本意是输出中文，可以直接写裸文本 `say(你好)` 省掉引号 |
| `E0105` | 非法转义 | `"a\qb"`、`"\u4F60"` | 只用 `\n` `\t` `\r` `\\` `\"` `\0` `\u{XXXX}`；Unicode 转义必须带花括号：`\u{4F60}` |
| `E0106` | 块注释未闭合 | `/* 没有结尾` | 补 `*/`。注意块注释**支持嵌套**，内层 `*/` 只关闭内层 |
| `E0107` | `#incloud` 写法错误 | `#include web`（拼错）、`say(1) #incloud web`（没独占一行）、光秃秃的 `#incloud`、`#incloud // 先留着`（参数为空） | 指令是 `#incloud`（**不是** `#include`），必须写在**行首、独占一行**，参数写到行尾且不能为空。字符串与注释里的 `#incloud` 只是普通文本，不会被当成指令 |

## 语法 E02xx

| 码 | 含义 | 典型触发 | 修复方式 |
| --- | --- | --- | --- |
| `E0201` | 意外 token | 顶层出现 `__init__` 之外的内容；写 `def main()`；REPL 里写 `__init__`；写光秃秃的 `elif` / `else`；使用 `while` / `for` / `return` / `break` / `continue` | 把代码移进 `__init__ { ... }`；`main()` 不写 `def`；`elif` / `else` 必须紧跟在 `if` 分支体之后；循环与 `return` 尚未实现（关键字已预留，会明确提示"暂不支持 X"），改用 `if` 组合或改写逻辑 |
| `E0202` | 缺少期望的 token | 括号/花括号不配对；`int a 1`（漏 `=`）；`def f`（漏 `(`）；`if a say(1)`（漏 `{`）；`else b {`（`else` 后跟了条件）；`if a = 1 {`（把 `==` 写成 `=`）；`cycle 3 {`（漏括号）；`say(hello world)`（裸文本带空格） | 逐个补齐 `{}` `()` `=`。条件后面必须紧跟 `{`；`else` 后面**不能**再有条件；判断相等要写 `==`；`cycle(N)` 的括号不能省；裸文本含空格时加引号（`say("hello world")`）——报错会精确指向多余的那个词 |
| `E0203` | `break` 不在 `cycle` 循环体内 | 在 `main()` 里直接 `break`；函数体里 `break`；循环结束后再 `break` | `break` 只能写在 `cycle` 循环体里，且必须**词法上**在循环体内（被循环调用的函数里写 `break` 也不行） |
| `E0206` | 同一行缺少语句分隔 | `__init__ { int a = 1 int b = 2 }` | 换行书写，或在同行的语句之间加 `;` |
| `E0207` | 在 `eval` / REPL 里使用 `#incloud` | `lemon eval "#incloud web"` | `#incloud` 需要文件上下文：把代码存成 `.lemon1` 文件后用 `lemon run <文件.lemon1>` 运行 |

## 结构与静态检查 E03xx

| 码 | 含义 | 典型触发 | 修复方式 |
| --- | --- | --- | --- |
| `E0301` | 缺少 `__init__` | 文件直接以 `main()` 开头 | 用 `__init__ { ... }` 把全部代码包起来 |
| `E0302` | `__init__` 出现多次 | 写了两个 `__init__ { }` | 合并成一个 |
| `E0303` | 缺少 `main()` | 只有变量声明和 `def` | 在 `__init__` 内补 `main() { ... }` |
| `E0304` | 裸表达式独立成句 | 单独一行写 `1`、`你好`、`count` | 表达式语句必须是函数调用；改成 `say(1)` / `say(你好)`；若本意是赋值，写成 `int a = ...` |
| `E0305` | 函数内定义函数 | `main() { def inner() { } }` | 把 `def inner` 移到 `__init__` 顶层（与 `main` 同级） |
| `E0306` | 名字冲突 | 变量重名、变量与函数同名、`def say()`、参数叫 `say`、顶层变量与内建同名、`main` 重复 | 改名。**内置函数名 `say` 不可被变量、函数、参数占用** |
| `E0307` | 类型不匹配 | **赋值**：`int a = 你好`、`int b = 1.5`、`int c = true`、`bool d = 1`、`text t = 10 / 4.0`。**运算**：`1 + 你好`、`你好 - 世界`、`-你好`、`+你好`。**比较/逻辑**：`1 == 你好`、`true == 1`、`你好 > 世界`、`true < false`、`1 && true`、`!1` | 按提示改类型或改表达式：文字用 `text`、真假用 `bool`、小数用 `double`（`int` 可隐式提升为 `double`，反向不行）。文本只能与文本做 `+`，且只能用 `==` / `!=` 比较；`bool` 只能与 `bool` 比较；`&&` `\|\|` `!` 只接受 `bool`（`1 && true` → 写成 `a > 0 && flag`） |
| `E0315` | 除数为字面量 0 | `say(7 / 0)`、`1.0 / 0.0` | 检查除数；确认不为 0 |
| `E0316` | `int` 乘方的指数为字面量负数 | `say(2 ** -1)` | 把底数写成小数即可：`2.0 ** -1` 得 `0.5`；或用 `1.0 / (2 ** 1)` |
| `E0317` | 取字段失败 | `name.code`（name 是 text）、`错误.行号` | 只有 catch 捕获到的错误值才有 `code` / `line` / `message`；注意 `.` 不能用于其他类型 |
| `E0308` | 调用未定义的函数 | `hello(你好)`、把 `say` 拼错成 `sya`、没写 `#incloud web` 就用 `fetchText` | 用 `def` 声明该函数，或改用内置 `say`。提示里会给出形近候选名；若是能力模块的函数，提示会直接告诉你"来自哪个模块、请在文件开头写 `#incloud X`" |
| `E0309` | 把变量当函数调用 | `int a = 1` 后写 `a(1)` | 确认是否漏了 `def`；变量不能调用 |
| `E0310` | 函数实参个数不符 | `def f(a, b)` 却调用 `f(1)` | 补齐或删掉多余实参 |
| `E0311` | `say` 实参个数不是 1 | `say()`、`say(1, 2)` | `say` 一次只输出一个值；多个值分多次调用 |
| `E0312` | 声明在后 / 形近名 | 顶层 `say(a)` 而 `a` 在后面才声明；`countt` 与 `count` 形近 | 把声明移到使用之前；或改回正确拼写。**这条也用来兜住"变量名打错被当成文本"** |
| `E0313` | `main` 带参数 | `main(a) { }` | `main()` 不能带参数；把需要的值改成 `__init__` 顶层变量 |
| `E0314` | 参数名重复 | `def f(a, a)` | 参数名必须互不相同 |
| `E0318` | `if` / `elif` 的条件不是 `bool` | `if a { }`（`a` 是 int）、`if 名字 { }`（text）、`if say(1) { }`（unit）、`if 错误 { }` | 条件必须是 `bool`。数字 → `if a != 0 { }` 或 `if a > 0 { }`；文本 → `if name != "" { }`；错误值 → `if 错误.code == E0405 { }`。分支体里已经有别的问题时会只报那一个，不再补 `E0318` |
| `E0319` | `cycle` 的次数不是 `int` | `cycle(1.5) { }`、`cycle(名字) { }`、`cycle(say(1)) { }`、`cycle(flag) { }` | 次数要写整数：`cycle(3)`。`cycle(0)` 合法（0 次）。次数可以来自 int 变量或函数参数 |
| `E0320` | `cycle` 的次数是字面量负数 | `cycle(-1) { }` | 负数没有意义；`cycle(0)` 表示一次都不执行。算出来的负数要到运行期才报 `E0409` |
| `E0321` | 内置函数的字面量参数不认识 | `keyboard(ww)`、`waitKey(空格键)` | 键名写单字符（`w`/`a`/`1`）或命名键 `space` `enter` `esc` `up` `down` `left` `right` `tab` `backspace`（中文别名：`空格` `回车` `上` `下` `左` `右`）。提示里会列全可用键名。键名来自变量时运行期报同一个错 |
| `E0322` | 把 bool 字面量写成 `True` / `False` | `if keyboard(w) == True { }` | Lemon 的 bool 字面量是**全小写** `true` / `false`；`keyboard` 本来就返回 bool，`== true` 是多余的，直接 `if keyboard(w) { }` 即可。若确实要输出 `True` 这个词，加引号 `say("True")` |

| `E0323` | 用了 `websets()` 但没有 `#incloud web` | 写 `websets() { ... }` 却忘了文件开头的 `#incloud web` | 在**文件最前面**补 `#incloud web`。模块没启用时只会报这一条，不会再把页面里的名字逐个报一遍 |
| `E0324` | `websets()` 结构缺项 | `websets() { }`（缺 `web.init()`）；`button { }`（缺 `to`） | 页面内容要写在 `web.init() { ... }` 里；`button` 必须写 `to <地址>`：`button { to "localhost:9000" }` |
| `E0325` | `websets()` 里有未知元素或非法内容 | `buton { }`（拼错）；`websets` 里写 `int a = 1`；`button` 里塞了 `to` 之外的东西 | 元素只有 `button` 与 `div`。`websets` 里只放 `web.init()`，`web.init` / `div` 里放 `button` / `div` / 文本，`button` 里只放 `to <地址>` |
| `E0348` | `div` 的属性写得不对 | `div (top (0,0;1,1)) { }`（名字不认识）；`div (color=#1;color=#2)`（重复）；`div (in (0,0;1,1) color=#2)`（漏 `;`） | 属性只有 `in (...)` 与 `color=...`，写在 `div` 后的括号里、用 `;` 分隔：`div (in (0,0;256,256); color=#ffffff) { ... }`。括号可整个省略 |

> `websets` / `web.init` / `button` / `to` / `div` / `in` / `color` 是**上下文关键字**：
> `say(button)`、`int to = 2`、`int div = 3` 仍然照常工作，不会因为多了这些构造就失效。

> `div` / `web.init` 里直接写的文本必须是 `text`：写 `say(hi)` 这类没有值的调用会报
> `E0307`（`say` 的结果是 `unit`，不是能显示的文本）。要放文字就直接写文本或字符串。

> `int 秒 = 1min` 会报 `E0307`：带时间单位的字面量一律是 `double`（秒）。
> 提示里会直接给出换算后的秒数，按提示改成 `double 秒 = 1min` 或 `int 秒 = 60`。

### 关于 E0312 与裸文本

Lemon 里"未声明的名字"会被当作**文本字面量**，因此：

- `say(你好)` 合法，输出 `你好`。
- 但 `say(coun)`（把 `count` 打错且不形近）也会"成功"，输出 `coun`。
  这类错误不会被报出，只能用 `lemon ast` 检查名字身份，或在顶层把变量用起来触发 E0312。

## 运行期 E04xx

| 码 | 含义 | 典型触发 | 修复方式 |
| --- | --- | --- | --- |
| `E0401` | 变量还没有值 | 顶层语句引用了尚未执行的声明（正常情况下会被 E0312 拦下） | 调整语句顺序 |
| `E0402` | 运行期类型不匹配 | 静态检查的兜底；或把函数名当值使用（如 `say(say)`） | 函数不能作为值传递，改成直接调用 |
| `E0403` | 调用层数过深 | 递归没有终止条件，或终止条件写错：`def loop() { loop() }`、`if n != 0 { 倒数(n) }`（忘了递减） | 用 `if` 写正确的终止条件，且保证参数在递归时**朝终止方向变化**：`if n > 1 { 倒数(n - 1) }` |
| `E0404` | 未预期的内部错误 | 解释器 bug | 记录最小复现代码并反馈 |
| `E0405` | 除数为 0 | 除数是算出来的，如 `int d = 1 - 1` 后 `say(7 / d)` | 在计算前确认除数不为 0：`if d != 0 { say(7 / d) }`。字面量 0 更早（E0315）就会被拦下。也可用 `try / catch` 兜住。**注意 `&&` / `\|\|` 会短路**，`d != 0 && 7 / d > 1` 是安全的写法 |
| `E0406` | 整数运算结果超出安全范围 | `big + 1` 溢出（`big = 9007199254740991`）、`2 ** 100` | 把参与运算的变量改用 `double`。这是刻意设计——避免整数静默变成不精确的值 |
| `E0407` | `int` 乘方的指数为负（算出来的） | `int n = 0 - 1` 后 `say(2 ** n)` | 把底数改成小数：`2.0 ** n` |
| `E0408` | 乘方结果不是有限数 | `(0.0 - 8.0) ** 0.5`（负数开偶次方根）、`2.0 ** 10000`（溢出） | 检查底数与指数的取值范围。**注意 `-8.0 ** 0.5` 不报错**——它是 `-(8.0 ** 0.5)`；要开方必须加括号 |
| `E0409` | `cycle` 的次数为负（算出来的） | `int n = 0 - 1` 后 `cycle(n)` | 检查次数的计算方式；`cycle(0)` 合法（0 次），只有负数才是错误。字面量负数更早（E0320）就会被拦下 |
| `E0410` | 拿不到终端键盘 | 在管道 / 重定向 / REPL / 编辑器里跑 `keyboard(w)` 或 `waitKey(w)` | 键盘判定需要**真实终端**：把程序写成 `.lemon1` 文件后在终端执行 `lemon run 文件.lemon1`。这是刻意设计——静默返回一堆 `false` 只会让人怀疑按键姿势 |
| `E0411` | `waitKey` 期间输入被关闭 | 用管道跑 `waitKey(q)`，输入流先结束 | 输入（Ctrl+D 或管道结束）已关闭，等不到后续按键；请检查输入来源，或改用 `keyboard` 轮询 |
| `E0412` | `sleep` 的时间为负 | `sleep(0 - 1)`、`sleep(负数变量)` | 负数没有意义；`sleep(0)` 合法（立即返回）。请检查时间的计算方式 |
| `E0413` | `openUrl` 打不开浏览器 | 系统里没有对应的打开命令（Linux 缺 `xdg-open`） | 需要先 `#incloud web`。`openUrl` 依赖系统自带的打开命令：Windows 的 `start`、macOS 的 `open`、Linux 的 `xdg-open` |
| `E0414` | `fetchText` 抓取失败 | 网址写错、服务器 4xx / 5xx、网络不通、超时（15 秒）、正文超过 4 MB、系统缺 `curl` | 需要先 `#incloud web`。核对网址可访问性；`fetchText` 依赖系统里的 `curl`。这是普通运行期错误，可以被 `try / catch` 接住 |

### 运行期错误的兜底（try / catch）

`E0403` / `E0405` / `E0406` / `E0407` / `E0408` / `E0413` / `E0414` 都可以用 `try / catch` 接住，让程序继续跑：

```lemon
try {
    say(7 / zero)
} catch (错误) {
    say(错误.code)      // E0405
    say(错误.line)      // 出错行号
    say(错误.message)   // 除数为 0，无法计算
}
```

注意 **`E0315` / `E0316` / `E0318` 等编译期错误接不到**——它们在程序开始执行前就中止了。

### 关于 E0403

递归是**可以写**的，但必须有能真正收敛的终止条件：

```lemon
def 倒数(n) {
    say(n)
    if n > 1 {             // ← 终止条件
        倒数(n - 1)         // ← 参数朝终止方向变化，缺了它就会一直递归
    }
}
```

两条最常见的踩坑：忘了写 `if`；或者 `if` 写了但递归调用时**参数没变**（`倒数(n)` 而不是 `倒数(n - 1)`）。
深度上限 200，超限抛 `E0403`，可以接住。

## 引入 E05xx（#incloud）

| 码 | 含义 | 典型触发 | 修复方式 |
| --- | --- | --- | --- |
| `E0501` | 引入的目标找不到 | `#incloud 工具库`（实际叫 `工具.lemon1`） | 核对文件名与位置（相对**当前文件**所在目录）。提示里会列出同目录下的 `.lemon1` 候选；不带 `.lemon1` 时会自动补，所以不写扩展名通常最省事 |
| `E0502` | 目标不是 `.lemon1` 源文件 | `#incloud package.json`、`#incloud 说明.txt` | `#incloud` 只能引 `.lemon1` 源文件或内置能力模块（当前可用：`web`）。JSON / 文本这类数据文件不在支持范围 |
| `E0503` | 引入层数过深 | 两个文件互相 `#incloud`（上限 32 层） | 检查引入关系，去掉环。正常程序不会到这个深度 |
| `E0504` | 被引入的文件里写了 `__init__` | `工具.lemon1` 被写成了一个完整程序 | 被引入的 `.lemon1` 是"零件"：**只写 `def` 与变量**，`__init__` 与 `main()` 由入口文件负责 |

> 被引入文件里的**普通错误**（类型、语法、运行期）报的还是原错误码，只是
> `--> 文件:行` 指向**那个文件**——排查时按提示里的文件名去看，不要盯入口文件。

## 用法 E09xx

| 码 | 含义 | 修复方式 |
| --- | --- | --- |
| `E0902` | 找不到文件 | 检查路径；Lemon 源文件后缀是 `.lemon1` |
| `E0903` | 无法读取文件 | 检查文件权限 |

---

## 退出码速查

| 码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 语言错误（词法 / 语法 / 静态检查 / 运行期） |
| `2` | 用法错误（文件不存在、参数不合法、未知选项） |
| `130` | 运行中被 Ctrl+C 中断（读键盘时终端处于 raw 模式，没有 SIGINT） |

## 调试手段

```bash
python scripts/lemon_run.py ast demo.lemon1      # 看语法树，名字会标注 (裸文本)/(变量)/(函数)/(内置函数)
python scripts/lemon_run.py tokens demo.lemon1   # 看 token 流，确认词法切分是否符合预期
python scripts/lemon_run.py check --json demo.lemon1   # 机器可读诊断（含 hint）
```

排查"为什么它被当成文本了"时，`ast` 是最直接的手段。
