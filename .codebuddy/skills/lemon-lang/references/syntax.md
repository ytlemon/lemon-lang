# Lemon 语法速查（v0.4.0）

## 1. 程序结构

```
__init__ {
    <变量声明>
    <函数声明>

    main() {
        <语句>
    }
}
```

- `__init__` **必须存在且唯一**，程序里不允许出现它之外的内容。
- `main()` **必须存在且唯一**，不写 `def`，不能带参数。
- 执行顺序：① 登记全部 `def` 与 `main` → ② 顺序执行 `__init__` 顶层语句 → ③ 调用 `main()`。

## 2. 词法

### 注释

```lemon
// 行注释

/* 块注释
   支持嵌套：/* 内层 */ 仍未结束
*/
```

### 关键字

| 关键字 | 作用 |
| --- | --- |
| `__init__` | 程序外壳 |
| `def` | 函数声明 |
| `main` | 主程序入口（不写 `def`） |
| `try` / `catch` | 捕获运行期错误 |
| `if` / `elif` / `else` | 条件分支 |
| `cycle` | 循环：`cycle(N)` 重复 N 次，`cycle()` 无限循环 |
| `break` | 跳出最内层的 `cycle` |
| `int` / `double` / `text` / `bool` | 四种类型 |
| `true` / `false` | bool 字面量 |
| `while` / `for` / `return` / `continue` | 已预留、**尚未实现**：写出来报 E0201「Lemon 暂不支持 X」 |

`say` 是内置函数名，不是关键字，但**不可被重定义**。

### 标识符

`Unicode 字母或下划线` 开头，后接 `Unicode 字母 / 数字 / 下划线`。
**中文标识符合法**：`text 名字 = 小明`。

### 字面量

| 形式 | 例子 | 说明 |
| --- | --- | --- |
| 整数 | `1`、`42`、`-0` | 超出 ±9007199254740991 报 E0103 |
| 小数 | `1.5`、`1e3`、`1.5e-2` | 小数点后必须有数字 |
| 引号文本 | `"你好"`、`"a\nb"` | 转义：`\n \t \r \\ \" \0 \u{XXXX}`；可跨行 |
| 裸文本 | `你好`、`你好，世界` | **不加引号直接写**，见下 |
| 布尔 | `true`、`false` | 关键字，类型 `bool`，不参与裸文本判定 |
| 时间 | `500ms`、`2s`、`1min`、`1.5h` | 换算成**秒**的 `double`；大小写都认 |

时间单位换算：`500ms`→`0.5`、`2s`→`2.0`、`1min`→`60.0`、`1.5h`→`5400.0`。
单位后面不能再跟字母数字（`1min2` 报 E0103）；不是单位时仍是 E0103「数字后面不能直接跟字符」（如 `1元`）。

**裸文本规则**：取一段连续的、不含空白且不含 ASCII 标点的字符；
能匹配标识符规则就产出标识符，否则直接产出文本。

```lemon
say(你好)              // ✅ 你好
say(你好，世界)         // ✅ 你好，世界     （全角标点不是分隔符）
say(Lemon v1)          // ❌ 含空格，被拆成两个词
say("Lemon v1")        // ✅ 需要空格时用引号
say(Hello-World)       // ❌ '-' 是保留符号，会截断
say("Hello-World")     // ✅
```

### 运算符

| 运算符 | 说明 |
| --- | --- |
| `+` | 二元；数值相加，`text + text` 拼接 |
| `-` | 二元；数值相减 |
| `*` | 二元；数值相乘 |
| `/` | 二元；数值相除，`int / int` 向零截断 |
| `**` | 二元；乘方，**右结合**，优先级最高 |
| `==` `!=` | 二元；相等 / 不等 → `bool` |
| `<` `<=` `>` `>=` | 二元；大小比较（仅数字） → `bool` |
| `&&` `\|\|` | 二元；逻辑与 / 或，**短路**，两侧必须 `bool` → `bool` |
| `-x` / `+x` | **一元**负号 / 正号；只接受 int / double，保持操作数类型 |
| `!x` | **一元**逻辑非；只接受 `bool` → `bool` |

优先级（低 → 高）：`\|\|` → `&&` → 比较（`== != < <= > >=`） → `+` `-` → `*` `/`
→ 一元 `+` `-` `!` → `**` → 调用 → 括号。
二元同级**左结合**；一元运算与 `**` **右结合**。
`**` 比一元正负号更紧，所以 `-2 ** 2` 是 `-4`；一元又比 `*` `/` 紧，所以 `-2 * 3` 是 `-6`。
六个比较运算符**同处一级**，`a == b < c` 解析为 `(a == b) < c`（几乎总是类型错误）。

```lemon
say(-1)           // -1
say(+5)           // 5
say(-(1 + 2))     // -3
say(1 - -1)       // 2
say(1 + +1)       // 2
say(- +1)         // -1
say(2 ** 10)      // 1024
say(2 ** 3 ** 2)  // 512   右结合
say(2 * 3 ** 2)   // 18
say(-2 ** 2)      // -4    -(2 ** 2)
say((0 - 2) ** 2) // 4
say(2 ** -1)      // ❌ E0316（int 乘方不支持负指数）
say(2.0 ** -1)    // 0.5
```

一元正负号**只接受 int / double**，`-你好` / `+你好` 报 E0307。`+` 不做类型转换。
一元 `!` **只接受 bool**，`!1` 报 E0307。

### if / elif / else

```lemon
if 分数 >= 90 {
    say(优秀)
} elif 分数 >= 60 {
    say(及格)
} else {
    say(不及格)
}
```

- 条件**不写括号**（写 `if (a > 0) {` 也合法，括号只是分组）。
- 条件类型**必须是 `bool`**，否则报 `E0318`：`if a {` ❌ → `if a != 0 {` ✅。
- `elif` 可重复任意次；`else` 至多一次且在最后，**后面不能再跟条件**。
- 按顺序求值条件，**命中第一个 `true` 就结束**，后面的条件不求值。
- 都不成立且无 `else` 时什么都不做。
- 每个分支体是**独立作用域**，可遮蔽外层同名变量，里面声明的变量不外泄。
- 可以嵌套，也可出现在 `__init__` 顶层、函数体、`try` / `catch` 块内。
- `if a = 1 {`（`==` 写成 `=`）报 E0202，并提示「判断相等要写 ==」。
- 条件里已有的错误（如名字笔误 E0312）不会被再补一个 E0318。

### cycle / break

```lemon
cycle(3) {          // 重复 3 次，体内 i 依次是 0 1 2
    say(i)
}

cycle() {           // 没次数 = 无限循环
    if i >= 5 {
        break       // 跳出最内层的 cycle
    }
    say(i)
}
```

| 写法 | 结果 |
| --- | --- |
| `cycle(3) { ... }` | 重复 3 次；`i` 依次 0 1 2 |
| `cycle(0) { ... }` | 一轮都不执行 |
| `cycle() { ... }` | 无限循环（`while true`），`i` 从 0 一直递增 |
| `i`（轮次变量） | `int`，从 0 开始；循环体每轮重新绑定；**遮蔽外层同名变量** |
| `cycle(2) { int i = 5 }` | ❌ E0306：与轮次变量重复声明 |
| `cycle(1.5)` / `cycle(你好)` / `cycle(say(1))` | ❌ E0319：次数必须是 int |
| `cycle(-1)` | ❌ E0320：字面量负数（运行前拦下） |
| `int n = 0 - 1` 后 `cycle(n)` | ❌ E0409：运行期次数为负 |
| `break` 在循环外 | ❌ E0203，解析阶段报出 |
| `cycle(3) { ... }` 后接 `break` | ❌ E0203（循环已结束，不再是循环体内） |

- 循环体**每轮都是新作用域**：体内声明的变量不带入下一轮，也不泄漏到循环外。
- `break` 只跳出**最内层**的 `cycle`；嵌套时外层继续。
- `break` 写在 `try` 里不会被 `catch` 吃掉（它不是错误）。
- `break` 必须**词法上**在循环体内：被循环调用的函数里写 `break` 报 E0203。
- `cycle()` 没有 `break` 就是死循环；`i` 只能读不能改（没有赋值语句）。

### 成员访问与错误值

`.` 是后缀成员访问，绑定最紧、可连写。**目前只有错误值有字段**：

| 表达式 | 类型 | 示例值 |
| --- | --- | --- |
| `错误.code` | `text` | `E0405` |
| `错误.line` | `int` | `6` |
| `错误.message` | `text` | `除数为 0，无法计算` |

对非错误值取字段、或取不存在的字段，都报 E0317。

### try / catch

```lemon
try {
    say(7 / zero)
} catch (错误) {
    say(错误.code)
}
```

- `try` 块**必须**紧跟 `catch (名字)`。
- 两个块**各自独立作用域**；外层变量两边都可见（`if` 分支体同理）。
- **只能捕获运行期错误**（E04xx）——语法 / 类型错误在运行前就中止了，接不到。
- `catch` 里再抛错会继续向外传播。
- 错误值不能存进变量，但可作为实参传给函数（参数是 `any`）。

### 保留符号（出现即报 E0102）

```
%                     取余
& |                   单个符号；要表示"并且/或者"请写 && / ||
[ ]                   列表
:                     不是语法符号；网址等含 : 的文本必须加引号
^ ~ ? @ \ ` '         其他
```

全角 `（` `）` `｛` `｝` `；` 也报 E0102，提示改用半角。全角逗号 `，` 与冒号 `：`
**不受影响**——它们是中文裸文本的常见内容（`say(你好，世界)` 合法）。

`#` 不在保留符号之列：它用于唯一的指令 `#incloud`。

### 指令 `#incloud`

把别的 `.lemon1` 源码或内置能力模块接进当前程序。

```lemon
#incloud 工具        // 并入同目录的 工具.lemon1（不带 .lemon1 会自动补）
#incloud web         // 启用网页能力模块
#incloud "lib/工具.lemon1" // 引号可有可无；可用相对路径
```

| 规则 | 说明 |
| --- | --- |
| 位置 | **行首、独占一行**（前面只允许空白）；写在行内报 E0107 |
| 拼写 | 就是 `#incloud`（**不是** `#include`）；写错报 E0107 并提示正确拼写 |
| 参数 | 一直取到行尾；行尾 `//` 注释会被剥掉（只有「空白 + `//`」或行首 `//` 才算注释，所以 `lib//工具.lemon1` 是完整路径）；参数为空报 E0107 |
| 目标解析 | 以 `.lemon1` 结尾 → 源文件（相对当前文件所在目录）；否则先查能力模块，再试 `<名字>.lemon1`；带别的扩展名（`package.json`）报 E0502；找不到报 E0501 并列出同目录 `.lemon1` 候选 |
| 放置 | 写在 `__init__` 之前 → 内容落到 `__init__ {` 之后；写在里面 → 就地展开 |
| 被引入文件 | **只写 `def` 与变量**，不要写 `__init__` / `main()`（写了报 E0504） |
| 重复 | 同一个文件只并入一次（菱形依赖没问题）；互相引入不会死循环 |
| 字符串/注释里 | 只是普通文本，不会被当成指令 |
| 作用范围 | 只在从文件运行时生效；`lemon eval` 与 REPL 里报 E0207 |

被引入文件里的错误，报错行号是**那个文件自己的**（`--> <文件名>:<行号>`），入口文件不受牵连。

### 标点

`(` `)` `{` `}` `,` `=` `;`

## 3. 语句分隔

**分号可写可不写，靠换行断句。**

- 下一个 token 出现在后续行 → 语句自然结束。
- 没写 `;` 且下一个 token 仍在同一行 → 报 E0206。
- 实参可以换行书写：

```lemon
say(
    你好
)
```

## 4. 变量声明

```lemon
int a = 1
double b = 1.23
text c = 你好
bool d = true
```

类型可赋值性：

| 源类型 | 目标类型 | 结果 |
| --- | --- | --- |
| 相同 | 相同 | ✅ |
| `int` | `double` | ✅ 隐式提升（`double b = 1` 得到 `1.0`） |
| `int` | `text` | ❌ E0307 |
| `double` | `int` | ❌ E0307（不支持取整转换） |
| `text` | `int` / `double` | ❌ E0307 |
| `bool` | 数字 / `text` | ❌ E0307 |
| 数字 / `text` | `bool` | ❌ E0307（要写比较，如 `bool b = a > 0`） |

**运算结果类型**（`promote`：只要有一侧是 `double` 就得 `double`）：

| 左 | 运算符 | 右 | 结果 |
| --- | --- | --- | --- |
| `int` | `+ - * /` | `int` | `int`（`/` 向零截断） |
| 数字 | `+ - * /` | 数字（含 `double`） | `double` |
| `text` | `+` | `text` | `text`（拼接） |
| `text` | `+ - * /` | 数字 | ❌ E0307 |
| 数字 | `+` | `text` | ❌ E0307 |
| `unit` | 任意 | 任意 | ❌ E0307（`say(...)` 无返回值） |
| `int` | `-x` / `+x`（一元） | — | `int` |
| `double` | `-x` / `+x`（一元） | — | `double` |
| `text` | `-x` / `+x`（一元） | — | ❌ E0307 |
| `int` | `**` | `int` | `int`（指数必须非负整数） |
| 数字 | `**` | 数字（含 `double`） | `double` |

**比较与逻辑的结果类型**：

| 左 | 运算符 | 右 | 结果 |
| --- | --- | --- | --- |
| 数字 | `== != < <= > >=` | 数字（含混用） | `bool`（`1 == 1.0` 为 `true`） |
| `text` | `== !=` | `text` | `bool` |
| `text` | `< <= > >=` | `text` | ❌ E0307（文本没有全序） |
| `bool` | `== !=` | `bool` | `bool` |
| `bool` | `< <= > >=` | `bool` | ❌ E0307 |
| 跨类型 | 任意比较 | 跨类型 | ❌ E0307 |
| `bool` | `&& \|\|` | `bool` | `bool`（**短路**：左侧定下结果则右侧不求值） |
| 非 `bool` | `&& \|\|` | 任意 | ❌ E0307 |
| `bool` | `!x`（一元） | — | `bool` |
| 非 `bool` | `!x`（一元） | — | ❌ E0307 |

函数参数是 `any`，参与任何运算都不算错，结果类型记为 `any`（比较与逻辑的结果记为 `bool`）。

除数若为**字面量 0** 报 E0315（运行前）；运行期才确定为 0 报 E0405。
`int` 运算结果超出 ±9007199254740991 报 E0406。
`int ** int` 的指数为负：字面量报 E0316（运行前），算出来的报 E0407。
`double` 乘方结果不是有限数（NaN / Infinity）报 E0408。

以上运行期错误（E0403 / E0405–E0408）都可以用 `try / catch` 接住；
E0315 / E0316 属编译期，接不到。

## 5. 函数

```lemon
def greet(who) {
    say(你好)
    say(who)
}
```

- 参数**不写类型**，静态检查中为 `any`（任何值都可传入）。
- 函数**没有返回值**，`def` 只描述副作用。
- 函数体里只能写变量声明与调用语句；**不能**再定义函数（E0305）。
- 参数名不能重复（E0314），不能占用内置名（E0306）。

## 6. 名字解析规则（决定"是变量还是裸文本"）

按优先级：

1. 能查到名字（变量 / 函数 / 内置 / 参数）→ 按该名字解释。
2. 查不到，且该名字是**声明在后面的顶层变量** → 报 E0312。顶层语句从上到下执行。
3. 查不到，但**与某个已声明名字编辑距离为 1**（仅 ASCII 名字、长度 ≥ 3）→ 报 E0312 并提示。
   - 该启发式在**调用位置**上会额外纳入内置函数名，所以 `sya(你好)` 会提示"是否想调用 say"；
     在实参位置上不纳入，所以 `say(bay)` 不会误报。
4. 其余情况 → 裸文本字面量。

**可见性**：

| 位置 | 可见的名字 |
| --- | --- |
| `__init__` 顶层语句 | 内置 + 全部函数（提升）+ **本行之前**声明的顶层变量 |
| 函数体内 | 内置 + 全部函数 + **全部顶层变量** + 参数 + 局部变量 |

函数体内能看到任意位置的顶层变量，因为 `main()` 在所有顶层语句执行完之后才被调用。

## 7. 内置函数

| 函数 | 签名 | 行为 |
| --- | --- | --- |
| `say` | `say(任意值) → unit` | 输出该值并**自动换行**；参数个数必须恰好为 1 |
| `keyboard` | `keyboard(键名) → bool` | **非阻塞**：这个键自上次读取后被按过就 `true`，立刻清零 |
| `waitKey` | `waitKey(键名) → unit` | **阻塞**：停在调用处直到该键被按下 |
| `sleep` | `sleep(秒数) → unit` | 暂停；**单位是秒**（`sleep(1)` = 1 秒，`sleep(1000)` = 1000 秒）。`sleep(0)` 合法，负数报 E0412 |

内置函数名都不可被变量 / 函数 / 参数占用（E0306）。

### 能力模块提供的函数

这些函数**必须先写 `#incloud <模块名>`** 才可见（否则调用报 E0308，提示会点明要补哪一行）：

| 模块 | 函数 | 签名 | 行为 |
| --- | --- | --- | --- |
| `web` | `openUrl` | `openUrl(网址) → unit` | 用系统默认浏览器打开；失败报 E0413 |
| `web` | `fetchText` | `fetchText(网址) → text` | 取回网页正文（超时 15 秒、上限 4 MB、依赖系统 `curl`）；失败报 E0414 |

网址只接受 `http://` / `https://` 开头（否则报 E0321），而且**必须加引号**：
`:` 不是 Lemon 的语法符号，`openUrl(https://example.com)` 报 E0102。
两者失败时都是普通运行期错误，可以被 `try` / `catch` 捕获。

### websets()：声明式网页界面（需要 `#incloud web`）

```lemon
#incloud web

__init__ {
    text 本地服务 = "localhost:9000"

    main() { say("逻辑照常跑在终端") }

    websets() {
        web.init() {
            button {
                to 本地服务                 // 可以引用变量
            }
            button {
                to "https://example.com"
            }
            div (in (0,0;256,128); color=#1f6feb) {
                一块蓝色面板
                div (in (8,8;120,48); color=#ffffff) { 嵌在里面的白块 }
            }
        }
    }
}
```

`main()` 跑完后生成与入口同名的 `.html`（`app.lemon1` → `app.html`，同目录）并打开浏览器；
`--no-open` 只落盘不开浏览器（**自动化里务必加**）。

| 规则 | 说明 |
| --- | --- |
| 位置 | `__init__` 顶层，与 `main()` 同级；写在函数体/分支里报 E0201 |
| 数量 | 至多一个（E0306）；不写就是纯终端程序 |
| 参数 | 不能带参数（E0202） |
| 解锁 | 必须有 `#incloud web`，否则报 E0323 |
| 根容器 | 元素写在 `web.init()` 里，缺了报 E0324；只能有一个（E0202） |
| 元素 | `button`、`div`、或**直接写一条文本**（裸文本/字符串/变量）；名字后跟 `{` 却不是这两者报 E0325 |
| `to` | `button` 的必需项（缺了报 E0324）；地址必须是 `text`（E0307），可写变量 |
| `in` | `div` 的位置盒子 `in (x1,y1;x2,y2)`（左上/右下，px）；四个坐标必须是数字（E0307），可写变量；不写则按普通块排布 |
| `color` | `div` 的背景色，必须是 `text`（E0307）；通常写颜色字面量 `#rrggbb` / `#rgb` |
| 属性写法 | `div (属性; 属性) { ... }`，括号可省略；只认 `in` 与 `color`，写错/重复/漏 `;` 报 E0348 |

**颜色字面量**：`#rrggbb` / `#rgb` 在词法层就是 `text`（值为原样 `#...`），
所以 `say(#ffffff)`、`text 主色 = #1f6feb` 都能用。

地址写入 `href` 时会规范化：不带协议一律补 `http://`。
`to "localhost:9000"` → `http://localhost:9000`；`to "https://x"` 原样。
**`localhost:9000` 必须补**——它在 URI 语法里合法（scheme 就叫 `localhost`），
浏览器会当成协议，点了毫无反应。

`websets` / `web.init` / `button` / `to` / `div` / `in` / `color` 都是**上下文关键字**，
只在上面这些位置才特殊，`say(button)`、`int to = 2`、`int div = 3` 照旧可用。
页面是纯静态的：只有按钮、div（位置 + 背景色）与文本，按钮文字就是它的地址。

在**管道 / 重定向 / REPL** 里调用键盘函数报 `E0410`（需要真实终端）；
`waitKey` 期间输入被关闭报 `E0411`。键名字面量拼错报 `E0321`。

输出格式：

| 值 | 输出 |
| --- | --- |
| `int 3` | `3` |
| `double 12.5` | `12.5` |
| `double 2`（整数值） | `2.0`（保留 `.0` 让类型可辨） |
| `double 1e21` | `1e+21`（科学计数法不再追加 `.0`） |
| `text 你好` | `你好` |
| `bool true` / `bool false` | `true` / `false` |

## 8. 命令行契约

```
lemon                        进入 REPL
lemon <文件.lemon1> / lemon run <文件.lemon1>     运行
lemon check [--json] [--stdin] [--warn-unused] <文件.lemon1>   只检查
lemon eval "<代码>"          求值片段（行号与输入对齐）
lemon ast <文件.lemon1>           打印语法树（标注名字身份）
lemon tokens <文件.lemon1>        打印词法单元
lemon help / --help          帮助
lemon version / --version    版本
```

`#incloud` 只在 `run` / `check` / `ast` 下生效——它们本来就在读文件；
`eval` 与 REPL 没有文件上下文，用到报 E0207。

退出码：`0` 成功、`1` 语言错误、`2` 用法错误。

REPL 命令：`:help`、`:symbols`、`:ast [代码]`、`:reset`、`:quit`。
REPL 中允许重复声明（覆盖）、允许裸表达式回显。

`check --json` 输出（**稳定契约**，编辑器插件依赖）：

```json
{"ok":true,"diagnostics":[]}
```

```json
{"ok":false,"diagnostics":[{"severity":"error","code":"E0307","message":"…","line":4,"col":17,"endLine":4,"endCol":20,"hint":"…"}]}
```

`line` / `col` / `endLine` / `endCol` 从 **1** 开始，`endCol` 不含结束位置，`col` 以 UTF-16 code unit 计。

## 9. 运行期

- 调用深度上限 **200**，超限报 E0403。
- 递归可以写，但必须有真正收敛的终止条件：`if n > 1 { 倒数(n - 1) }`。
- 宿主栈溢出会被转译为 E0403，不暴露宿主堆栈。
- 运行期错误附带 Lemon 层调用栈（最外层在前）。
- **错误发生前的输出会保留**；程序输出走 stdout，诊断走 stderr，严格分流。
- `try` / `catch` 与 `if` 分支体各自套一层作用域，嵌套层级不额外增加调用深度。
