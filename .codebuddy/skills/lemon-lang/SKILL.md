# Lemon 语言

## 概述

Lemon 是一门 C 风格命令式语言，源文件后缀 `.lemon1`。本技能提供编写正确 Lemon 代码所需的全部规则、
常见错误的修复方式，以及定位并调用本地解释器的脚本。

## 八条最容易踩的规则

1. **`__init__` 是必需外壳，`main()` 不写 `def`。** 程序结构固定为 `__init__ { ... main() { ... } ... }`。
2. **变量声明必须带类型**：`int` / `double` / `text` / `bool`。类型不匹配在运行前就会报错，程序不会执行。
3. **没声明的名字会被当成文本**（裸文本）。因此 `text t = 你好` 合法；
   但 **`say` 的实参必须是引号字符串**——`say(你好)` 报 E0344，要写 `say("你好")`。
   这也意味着变量名打错不会报"未定义"，只会按裸文本处理——只有与已声明的名字形近时才会报 E0312。
4. **`int / int` 向零截断**：`7 / 2` 得 `3`，不是 `3.5`。要小数就让其中一侧是 `double`（`7 / 2.0` 得 `3.5`）。
5. **`if` 的条件必须是 `bool`，而且不写括号**：`if a > 0 { ... }`。
   写 `if a { ... }`（`a` 是 int）报 E0318——Lemon 没有"非 0 即真"，要写 `if a != 0 { ... }`。
6. **正负号与逻辑非直接写**：`-1`、`+5`、`-x`、`!(a > 0)` 都合法。
   一元 `+` 只是数值恒等，不做类型转换；`!` 只接受 `bool`。
7. **时间单位是秒，不是毫秒**：`sleep(1)` 停 1 秒，所以 `sleep(1000)` 是 1000 秒（≈17 分钟）。
   拿不准就写带单位的 `sleep(1000ms)`——`ms` / `s` / `min` / `h` 后缀会换算成秒。
8. **网址必须加引号**：`:` 不是 Lemon 的语法符号，`openUrl(https://example.com)` 报 E0102，
   要写 `openUrl("https://example.com")`；`websets()` 里的 `to localhost:9000` 同理，
   要写 `to "localhost:9000"`。用 `web` 模块（含 `websets()`）前必须在**文件行首**写 `#incloud web`。

## 标准写法

```lemon
__init__ {
    int count = 3
    double price = 12.5
    text name = Lemon
    bool 有货 = count > 0

    def greet(who) {
        say(你好)
        say(who)
    }

    def 报价() {
        if price < 10 {
            say(便宜)
        } elif price < 100 {
            say(适中)
        } else {
            say(昂贵)
        }
    }

    main() {
        say(count + 1)                 // 4
        say(price / 4)                 // 3.125
        say(1 + 2 * 3)                 // 7
        say(0 - count)                 // -3
        say(name + 语言)                // Lemon语言
        say(有货 && price < 100)        // true
        greet(小明)
        报价()
    }
}
```

执行顺序：先按顺序执行 `__init__` 里的顶层语句，最后自动调用 `main()`。
所有 `def` 与 `main` 都整体提升，调用不受声明顺序限制。

## 工作流

### 写新代码

1. 以 `__init__ {` 开头，在其中声明变量与 `def`，最后写 `main() { ... }`。
2. 语句之间用**换行**分隔；只有把多条语句写在同一行时才需要 `;`。
3. 输出文本时优先用裸文本（不加引号）；文本中含空格或半角符号（`-`、`+`、`.` 等）时改用 `"..."`。
4. 缩进仅用于阅读，没有语法含义。
5. 写完用 `scripts/lemon_run.py` 校验，不要凭猜测交付。

### 排查报错

1. 取出错误码，在 `references/errors.md` 中查找对应条目与修复方式。
2. 先判断是否属于**版本边界**（见下节）。如果代码用到了 v0.2.0 未实现的特性，
   报 E0102 是预期行为，正确做法是改写代码或明确告知用户当前版本不支持，而不是"修 bug"。
3. `lemon ast <文件>` 会把每个名字标注为 `(裸文本)` / `(变量)` / `(函数)` / `(内置函数)`，
   这是排查"为什么它被当成文本了"最快的办法。

### 运行与检查

统一使用 `scripts/lemon_run.py`，它会自动定位解释器（`dist/lemon.exe` → `dist/lemon.cjs` + node →
`bin/lemon.js` + node → 系统 PATH）：

```bash
python scripts/lemon_run.py run demo.lemon1        # 运行脚本
python scripts/lemon_run.py check demo.lemon1      # 只做词法与静态检查
python scripts/lemon_run.py check --json demo.lemon1   # 机器可读诊断
python scripts/lemon_run.py eval "say(你好)"       # 求值一段代码
python scripts/lemon_run.py --print-command run demo.lemon1   # 只看会执行什么
```

退出码：`0` 成功、`1` 语言错误、`2` 用法错误。

## 运算

已支持：`+ - * /` 与括号。`*` `/` 优先于 `+` `-`，同级左结合。

| 表达式 | 结果 | 说明 |
| --- | --- | --- |
| `1 + 2 * 3` | `7` | 优先级 |
| `(1 + 2) * 3` | `9` | 括号 |
| `10 - 2 - 3` | `5` | 左结合 |
| `7 / 2` | `3` | int 除法向零截断 |
| `7 / 2.0` | `3.5` | 含 double 提升 |
| `3 * 1.0` | `3.0` | 整数值的 double 保留 `.0` |
| `-1` / `-a` / `-(a + b)` | `-1` / `-5` / `-6` | 一元负号，保持操作数类型 |
| `+5` / `+a` | `5` / `5` | 一元正号是数值恒等 |
| `-2 * 3` / `+2 * 3` | `-6` / `6` | 一元运算优先于 `*` `/` |
| `2 ** 10` | `1024` | 乘方，优先级最高且右结合 |
| `2 ** 3 ** 2` | `512` | 右结合，即 `2 ** (3 ** 2)` |
| `2 * 3 ** 2` | `18` | 即 `2 * (3 ** 2)` |
| `-2 ** 2` | `-4` | 乘方比一元负号更紧，即 `-(2 ** 2)`；要 `4` 写 `(0 - 2) ** 2` |
| `2 ** 0.5` | `1.4142135623730951` | 一侧是 double 就得 double |
| `2 ** -1` | ❌ E0316 | int 乘方的指数不能为负，改写 `2.0 ** -1` |
| `2 ** 100` | ❌ E0406 | 整数结果超出安全范围 |
| `(0.0 - 8.0) ** 0.5` | ❌ E0408 | 负数开偶次方根，结果不是有限数 |
| `1 - -1` / `1 + +1` / `- +1` | `2` / `2` / `-1` | 与二元运算连写 |
| `你好 + 世界` | `你好世界` | text + text 拼接 |
| `1 + 你好` | ❌ E0307 | 数字与文本不能相加 |
| `你好 - 世界` | ❌ E0307 | 文本只能做 `+` |
| `-你好` / `+你好` | ❌ E0307 | 一元正负号只接受 int / double |
| `7 / 0` | ❌ E0315 | 字面量 0 作除数，运行前报错 |

`int` 运算结果超出 ±9007199254740991 报 E0406，提示改用 `double`。

## 比较、逻辑与条件分支

```lemon
if 分数 >= 90 {
    say(优秀)
} elif 分数 >= 60 {
    say(及格)
} else {
    say(不及格)
}
```

| 表达式 | 结果 | 说明 |
| --- | --- | --- |
| `1 == 1.0` | `true` | int 与 double 按数值比较 |
| `1 < 2` / `2 <= 2` / `3 > 4` / `3 >= 4` | `true` / `true` / `false` / `false` | 大小比较只接受数字 |
| `你好 == 你好` | `true` | 文本只能用 `==` / `!=` |
| `你好 > 世界` | ❌ E0307 | 文本没有全序 |
| `true == false` | `false` | bool 之间只能用 `==` / `!=` |
| `1 == 你好` / `true == 1` | ❌ E0307 | 跨类型不能比较 |
| `t && f` / `t \|\| f` / `!t` | `bool` | `&&` `\|\|` 两侧必须 bool，`!` 同理 |
| `false && 1 / zero > 0` | `false` | **短路**：右侧不求值，不会报除零 |
| `1 && true` / `!1` | ❌ E0307 | 数字不是 bool |
| `bool b = a > 0` | ✅ | 比较的结果就是 bool，可以直接存 |
| `int i = a > 0` | ❌ E0307 | 比较结果不是 int |
| `if a { }`（a 是 int） | ❌ E0318 | 条件必须是 bool：改 `if a != 0 { }` |
| `if 名字 { }`（text） | ❌ E0318 | 改 `if 名字 != "" { }` |
| `if say(1) { }` | ❌ E0318 | `say` 没有返回值 |
| `if a = 1 { }` | ❌ E0202 | `==` 误写成 `=`，提示会指出 |
| `elif` / `else` 单独出现 | ❌ E0201 | 必须紧跟在 `if` 分支体之后 |

`if` 的要点：条件**不写括号**；`elif` 可重复、`else` 至多一个且在最后（`else` 后不能再跟条件）；
**命中第一个 `true` 就结束**；分支体是**独立作用域**（可遮蔽外层，内层声明不外泄）；可以嵌套。

## 循环：cycle

```lemon
cycle(3) {              // 重复 3 次，体内 i 依次是 0 1 2
    say(i)
}

cycle() {               // 没有次数 = while true
    if i >= 5 {
        break           // 跳出最内层的 cycle
    }
    say(i)
}
```

| 写法 | 含义 |
| --- | --- |
| `cycle(3) { ... }` | 重复 3 次；`cycle(0)` 一轮都不执行 |
| `cycle() { ... }` | 无限循环，`i` 从 0 一直递增，靠 `break` 结束 |
| `i` | 轮次变量，**int，从 0 开始**，循环体每轮重新绑定；会遮蔽外层同名变量 |
| `break` | 跳出**最内层**的 `cycle`；只能出现在循环体内（否则 E0203） |
| `cycle(1.5)` / `cycle(你好)` | ❌ E0319：次数必须是 int |
| `cycle(-1)` | ❌ E0320：字面量负数（运行前）；算出来的负数报 E0409（运行期） |
| `cycle(2) { int i = 5 }` | ❌ E0306：与轮次变量 `i` 重复声明 |

要点：

- 循环体**每轮都是新作用域**，体内声明的变量不带入下一轮，也不泄漏到循环外。
- `break` 写在 `try` 里**不会被 catch 吃掉**（它不是错误）。
- `break` 必须**词法上**在循环体内：被循环调用的函数里写 `break` 会报 E0203。
- **`i` 只能读，不能改**——Lemon 目前没有赋值语句，循环体里无法累积状态。
- 常见写法："最多试 N 次，满足条件就提前收工"：`cycle(N) { if 条件 { break } ... }`。

## 键盘输入

| 函数 | 返回 | 行为 |
| --- | --- | --- |
| `keyboard(键)` | `bool` | **非阻塞**：这个键自上次读取后被按过就 `true`，并立刻清零 |
| `waitKey(键)` | `unit` | **阻塞**：停在调用处直到该键被按下 |

```lemon
cycle() {
    if keyboard(w) { say(前进) }
    if keyboard(q) { break }
}

waitKey(space)          // 按空格继续
```

- 键名：单个字符（`w`/`a`/`1`，大小写等价）或 `space` `enter` `esc` `up` `down` `left` `right` `tab` `backspace`；中文别名 `空格` `回车` `上` `下` `左` `右`。
- **语义是"按过就算"，不是"按住"**：终端没有 keyup 事件。按一次只产生一个 `true`；读取前连按也只算一次（锁存，不计数）。想要"按住"的手感就在 `cycle()` 里持续轮询。
- 键名写成**字面量**时运行前校验：`keyboard(ww)` → ❌ E0321（会列出可用键名）。键名来自变量则运行期报同一个错。
- **必须真实终端**：管道、重定向、REPL 里报 `E0410`（不静默返回 false）；`waitKey` 遇到输入结束报 `E0411`。
- `keyboard` / `waitKey` 是内置名，不可被变量/函数/参数占用（E0306）。
- 写 `if keyboard(w) == true` 是多余的（本来就返回 bool），直接 `if keyboard(w) {`；注意是**小写** `true`，写成 `True` 报 E0322。
- `cycle()` 里轮询键盘是满速空转，会占满一个 CPU 核心。

## 时间与 sleep

**Lemon 里的时间一律以秒为单位。** `sleep(1)` 停 1 秒 —— 所以 `sleep(1000)` 是 1000 秒（≈17 分钟），
从毫秒系语言过来极易踩，拿不准就写带单位的 `sleep(1000ms)`。

数字后面可以直接跟时间单位，**一律换算成"多少秒"的 `double`**：

| 写法 | 值 | 写法 | 值 |
| --- | --- | --- | --- |
| `500ms` | `0.5` | `2s` | `2.0` |
| `1min` | `60.0` | `1.5h` | `5400.0` |

```lemon
sleep(1)         // 1 秒
sleep(0.5)       // 半秒
sleep(500ms)     // 同上
sleep(1min)      // 一分钟

say(1min + 30)   // 90.0 —— 换算后就是普通数字，可以参与运算
int 秒 = 1min    // ❌ E0307：带单位的时长是 double，提示里会给出 60
```

- 大小写都认（`1S` / `1Min`）；单位后面不能再跟字母数字，`1min2` 报 E0103。
- `sleep(0)` 合法（立即返回）；**负数报 E0412**。
- 精度受系统定时器粒度影响，偏差约 15 毫秒量级。
- 长睡眠期间 Ctrl+C 也能立刻停下（前提是程序用过 `keyboard` / `waitKey`）。
- `sleep` 是内置名，不可被占用（E0306）。

**限帧**是典型用法——不加 sleep 的 `cycle()` 会满速空转占满一个 CPU 核心：

```lemon
cycle() {
    if keyboard(q) { break }
    say(帧)
    sleep(20ms)      // 约 50 帧/秒
}
```

## 错误处理

```lemon
try {
    say(7 / zero)
} catch (错误) {
    say(错误)            // E0405 除数为 0，无法计算
    say(错误.code)       // E0405
    say(错误.line)       // 6      ← 出错行号
    say(错误.message)    // 除数为 0，无法计算
}
```

- `try` 块**必须**紧跟 `catch (名字)`；两个块**各自独立作用域**，外层变量两边都可见。
- **只能捕获运行期错误**（E04xx）。语法 / 类型错误（E01xx / E02xx / E03xx）在程序开始执行前就中止了，`try` 接不到。
- `catch` 块里再抛错会继续向外传播。
- 错误值**不能存进变量**（`text t = 错误` 报 E0307），但可以作为实参传给函数（参数是 `any`）。
- 当前可捕获的错误：`E0403` 调用过深、`E0405` 除零、`E0406` 整数溢出、`E0407` int 负指数、`E0408` 非有限结果。

**常见用法**：`try` 接住跑飞的递归（`E0403`）让程序继续。递归本身是允许的，
用 `if` 写终止条件即可：`if n > 1 { 倒数(n - 1) }`。

## 引入：#incloud

`#incloud` 是 Lemon **唯一的指令**，把别的 `.lemon1` 源码或内置能力模块接进当前程序。

```lemon
#incloud 工具        // 并入同目录的 工具.lemon1（自动补 .lemon1）
#incloud web         // 启用网页能力模块

__init__ {
    main() {
        打招呼(小明)                       // 来自 工具.lemon1
        say(fetchText("https://example.com"))   // 来自 web 模块
    }
}
```

| 规则 | 说明 |
| --- | --- |
| 位置 | 必须写在**行首、独占一行**；行尾可跟 `//` 注释。写在行内报 E0107 |
| 拼写 | 就是 `#incloud`（不是 `#include`）；写错报 E0107 并提示正确拼写 |
| 参数 | 写到行尾，引号可有可无；不带 `.lemon1` 会自动补 |
| 目标 | 以 `.lemon1` 结尾 → 源文件；否则先查能力模块，再试 `<名字>.lemon1` |
| 放置 | 写在 `__init__` 之前 → 内容落到 `__init__ {` 之后；写在里面 → 就地展开 |
| 被引入文件 | **只写 `def` 与变量**，不要写 `__init__` / `main()`（写了报 E0504） |
| 重复 | 同一个文件只并入一次（菱形依赖没问题）；互相引入不会死循环 |
| 找不到 | 报 E0501 并列出同目录的 `.lemon1` 候选 |
| 数据文件 | `#incloud package.json` 报 E0502——只支持 `.lemon1` 源文件 |
| 作用范围 | 只在从文件运行时生效；`lemon eval` 与 REPL 里报 E0207 |

被引入文件里的错误，报错行号是**那个文件自己的**（Lemon 会做行来源映射），排查时直接看
`--> <文件名>:<行号>` 指向哪里。

### 能力模块：web

| 函数 | 返回 | 行为 |
| --- | --- | --- |
| `openUrl(网址)` | `unit` | 用系统默认浏览器打开 |
| `fetchText(网址)` | `text` | 取回网页正文（超时 15 秒、上限 4 MB、依赖系统 `curl`） |

- 网址只接受 `http://` / `https://` 开头，否则报 E0321（运行期）。
- 失败报 E0413 / E0414，都是普通运行期错误，**可以被 `try` / `catch` 捕获**。
- 忘了写 `#incloud web` 就调用，静态检查报 E0308 并提示补哪一行。
- `openUrl` 会真的弹出浏览器窗口——在自动化 / 无界面环境里别用它。

### 网页界面：websets()

`#incloud web` 还解锁 `websets()`，与 `main()` **同级**（写在 `__init__` 顶层）：

```lemon
#incloud web

__init__ {
    text 本地服务 = "localhost:9000"

    main() {
        say("逻辑照常跑在终端")
    }

    websets() {
        web.init() {
            button {
                to 本地服务                 // 可以引用变量
            }
            button {
                to "https://example.com"
            }
            div (in (0,0;256,128); color=#1f6feb) {
                一块蓝色面板                    // 直接写文本内容
                div (in (8,8;120,48); color=#ffffff) {
                    嵌在里面的白块              // 嵌套 div，坐标相对父容器
                }
            }
        }
    }
}
```

| 规则 | 说明 |
| --- | --- |
| 位置 | `__init__` 顶层，与 `main()` 同级；写在函数体/分支里报 E0201 |
| 数量 | 至多一个；不写就是纯终端程序 |
| 参数 | 不能带参数（E0202） |
| 解锁 | 必须有 `#incloud web`，否则报 E0323 |
| 根容器 | 元素必须写在 `web.init()` 里，缺了报 E0324；只能有一个（E0202） |
| 元素 | `button`、`div`、以及**直接写一条文本**（裸文本/字符串/变量）；名字后跟 `{` 却不是这两者报 E0325 |
| `to` | `button` 必需项，缺了报 E0324；地址必须是 `text`（E0307），可以写变量 |
| `in` | `div` 的位置盒子 `in (x1,y1;x2,y2)`：两点是左上/右下，单位 px；四个坐标都得是数字（int/double，可写变量），否则 E0307。不写就不做绝对定位 |
| `color` | `div` 的背景色，值必须是 `text`；通常写颜色字面量 `#rrggbb` / `#rgb`（E0307） |
| 属性写法 | `div (属性; 属性) { ... }`，括号可整个省略；属性只认 `in` 与 `color`，写错/重复/漏 `;` 报 E0348 |

**颜色字面量 `#rrggbb` / `#rgb`**：不是独立语法构造，词法层直接当成 `text`，
所以 `say(#ffffff)`、`text 主色 = #1f6feb` 都能用；编辑器里点这个值会弹出取色器。

**产出**：`main()` 跑完后生成与入口同名的 `.html`（`app.lemon1` → `app.html`，同目录），
并用系统默认浏览器打开。加 `--no-open` 只落盘不开浏览器——**自动化/CI 里务必加**，
否则会真的弹出浏览器窗口。

地址不带协议会自动补 `http://`：`to "localhost:9000"` → `http://localhost:9000`。
这一步是必须的——`localhost:9000` 在 URI 语法里合法（scheme 就叫 `localhost`），
浏览器会把它当协议，点了毫无反应。

**`websets` / `web.init` / `button` / `to` / `div` / `in` / `color` 都是上下文关键字**，
只在上述位置才特殊，所以 `say(button)`、`int to = 2`、`int div = 3` 照旧能用。
页面是纯静态的：只有 `button`、`div`（位置 + 背景色）与文本，没有循环渲染、没有点击回调，
`button` 的文字就是它的地址。

## 版本边界（尚未实现，遇到时不要尝试"修复"）

- 取余 `%`、列表 `[ ]`、单个 `&` / `|` —— 报 E0102
- 全角括号 `（）｛｝；` —— 报 E0102 并提示改用半角（全角逗号 `，` 不受影响，仍是裸文本内容）
- `while` / `for` / `continue` —— 关键字已预留，报 E0201「暂不支持」
- 函数返回值与 `return` —— 关键字已预留，报 E0201「暂不支持」
- 复合数据结构：列表、元组、下标访问
- 函数值传递（函数名不能单独作为值使用）
- `#incloud` 只能引**相对路径下的单个 `.lemon1` 文件**与内置能力模块：按包名引入、目录级引入、
  `.json` / `.txt` 等数据文件都不支持（分别报 E0502 / E0501）
- `websets()` 只产**静态页面**：没有本地服务器、没有循环渲染列表、没有点击回调与状态；
  元素只有 `button`、`div`（仅 `in` / `color` 两个属性）与文本，按钮文字就是地址
- **赋值语句**：`=` 只出现在变量声明里，没有 `x = x + 1` 这种重新赋值

循环请用 `cycle`；没有赋值语句意味着循环体里不能累积状态，这一点在写代码时要提前考虑到。
