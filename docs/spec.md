# Lemon 语言规范 v1.0.0

本文档描述 Lemon 的完整语法与语义。所有内容与 `src/lang/` 下的实现一一对应，
测试用例（`tests/`、`tests/fixtures/`）即为本文档的可执行版本。

---

## 1. 词法

### 1.1 源文件

- 后缀 `.lemon1`，编码 UTF-8。
- 开头的 UTF-8 BOM 会被自动剥离。
- 换行可以是 `LF` 或 `CRLF`，两者行号计算一致。

### 1.2 空白与注释

空白（空格、制表符、各类 Unicode 空白）在词法阶段被跳过，**不产生 Token**。

```lemon
// 行注释：到行尾结束

/* 块注释
   支持嵌套：/* 内层 */ 仍在注释中
*/
```

行号信息编码在每个 Token 的 `span` 中，因此「换行」不产生独立 Token
——语句分隔由解析器依据行号判定（见 §2.4）。

### 1.3 关键字

| 关键字 | 含义 |
| --- | --- |
| `__init__` | 程序外壳，必需且唯一 |
| `def` | 函数声明 |
| `main` | 主程序入口声明 |
| `try` / `catch` | 捕获运行期错误 |
| `if` / `elif` / `else` | 条件分支 |
| `cycle` | 循环；`cycle(N)` 重复 N 次，`cycle()` 无限循环 |
| `break` | 跳出最内层的 `cycle` |
| `return` | 从函数返回值，或提前结束函数；见 §2.11 |
| `int` / `double` / `text` / `bool` | 四种变量类型 |
| `true` / `false` | bool 字面量 |
| `while` / `for` / `continue` | **已预留、尚未实现**：出现即报 `E0201` 并说明原因 |

`say` / `ask` / `keyboard` / `waitKey` 是**内置函数名**而非关键字：它们通过静态检查解析，
可以被诊断但不可被重定义（见 §4.6）。

### 1.4 标识符

```
标识符 := 标识符首字符 标识符后续字符*
标识符首字符 := Unicode 字母 | 下划线
标识符后续字符 := Unicode 字母 | Unicode 数字 | 下划线
```

因此中文标识符合法：`text 名字 = 小明`。

### 1.5 字面量

**整数**：十进制数字序列。超出安全整数范围（±9007199254740991）报 `E0103`。

**小数**：`1.0`、`1.23`、`1e3`、`1.5e-2`。
小数点后必须跟数字（`1.` 报 `E0103`）。

**文本**：
- 引号形式：`"你好"`，支持转义 `\n` `\t` `\r` `\\` `\"` `\0` `\u{XXXX}`；
  未知转义报 `E0105`，未闭合报 `E0104`。引号字符串可以跨行。
- **裸文本**：不加引号直接写。扫描规则是「取一段连续的、不含空白且不含 ASCII 标点的字符」，
  若这段字符匹配标识符规则则产出标识符，否则直接产出文本。

```lemon
text 问候 = 你好     // 裸文本：别的场合可以直接写
say("你好")         // ✅ 在 say 里要加引号
say(你好)           // ✗ E0344：say 的文本要加引号
say(Hello-World)    // ✗ E0201：'-' 是保留符号，会截断裸文本
say(a)              // 标识符；是变量还是裸文本由静态检查决定（见 §3.4）
```

> **`say` 的文本必须加引号**（`E0344`）。原因：`say(x)` 里的名字到底是“变量”还是“想输出的
> 文字”最容易被写混。变量 `say(a)`、数字 `say(1)`、带引号的字符串都不受影响；
> 其它位置（变量声明、拼接、比较等）的裸文本照旧可用。

**裸文本不含空白**：`say(——— Lemon ———)` 这种带空格的文本本来就要写成
`say("——— Lemon ———")`。

**布尔**：`true` 与 `false` 是关键字，类型为 `bool`。它们不参与裸文本判定，
因此 `say(true)` 输出 `true` 而不是把 `true` 当字符串。

**时间**：数字后面可以紧跟时间单位，写成 `500ms`、`2s`、`1min`、`1.5h`
（大小写都认）。这类字面量**一律求值为 `double`，单位统一换算成秒**：

| 写法 | 值 | 说明 |
| --- | --- | --- |
| `500ms` | `0.5` | 毫秒 |
| `2s` | `2.0` | 秒 |
| `1min` | `60.0` | 分 |
| `1.5h` | `5400.0` | 小时 |

单位后面不能再跟字母数字（`1min2` 报 `E0103`）；不是单位时仍按原来的规则报
「数字后面不能直接跟字符」（如 `1元`）。

因为换算结果是 `double`，`int 秒 = 1min` 会报 `E0307`（提示里会给出换算后的秒数）。
**Lemon 里的时间一律以秒为单位**：`sleep(1)` 停 1 秒，因此 `sleep(1000)` 是 1000 秒。

### 1.6 运算符

| 运算符 | 说明 |
| --- | --- |
| `+` | 二元；数值相加，`text + text` 拼接 |
| `-` | 二元；数值相减 |
| `*` | 二元；数值相乘 |
| `/` | 二元；数值相除，`int / int` 向零截断 |
| `**` | 二元；乘方，**右结合**，优先级最高 |
| `==` `!=` | 二元；相等 / 不等，结果 `bool` |
| `<` `<=` `>` `>=` | 二元；大小比较（仅数字），结果 `bool` |
| `&&` `\|\|` | 二元；逻辑与 / 或，**短路求值**，两侧必须 `bool`，结果 `bool` |
| `-x` | **一元**负号；取负，保持操作数类型 |
| `+x` | **一元**正号；数值恒等，保持操作数类型 |
| `!x` | **一元**逻辑非；操作数必须 `bool`，结果 `bool` |
| `.` | **后缀**成员访问；绑定最紧，可连写 `a.b.c` |
| `[ ]` | **后缀**下标读取；与 `.` 同级，可以互相交替连写 `a.b[0].c` |

优先级（低 → 高）：
`||`  →  `&&`  →  比较（`== != < <= > >=`）  →  `+` `-`
→  `*` `/`  →  一元 `+` `-` `!`  →  `**`  →  调用  →  `.` `[ ]`  →  括号

- 二元同级**左结合**；一元运算与 `**` **右结合**，因此 `- -1` 等于 `1`、
  `2 ** 3 ** 2` 等于 `512`、`!!flag` 等于 `flag`。
- `**` 优先级高于一元正负号，因此 `-2 ** 2` 等于 `-(2 ** 2)` 即 `-4`；
  想要 `4` 请写 `(0 - 2) ** 2`。
- 指数的位置用「一元表达式」解析，所以 `2 ** -1` 合法。
- **六个比较运算符同处一级**（不像 C 那样再分两级），因此 `a == b < c` 解析为
  `(a == b) < c`；该写法几乎总是类型错误，报错会指出具体类型。

```lemon
say(-1)          // -1
say(+5)          // 5    ← 数值恒等，不做任何转换
say(-2 * 3)      // -6
say(1 - -1)      // 2
say(1 + +1)      // 2
say(- +1)        // -1
say(2 ** 10)     // 1024
say(2 ** 3 ** 2) // 512  ← 右结合，即 2 ** (3 ** 2)
say(2 * 3 ** 2)  // 18   ← 即 2 * (3 ** 2)
say(-2 ** 2)     // -4   ← 即 -(2 ** 2)
say((0 - 2) ** 2) // 4
say(1 + 2 > 2)   // true ← 比较低于算术，即 (1 + 2) > 2
say(a > 0 && b > 0)  // && 低于比较
say(!a || b)     // ! 优先于 ||，即 (!a) || b
```

一元正负号都**只接受 `int` 与 `double`**：`-你好`、`+你好` 报 `E0307`。
一元 `+` 不做类型转换（不会把 `text` 变成数字），它只是恒等。
一元 `!` **只接受 `bool`**：`!1` 报 `E0307`。

### 1.7 保留符号

以下字符尚未定义，出现即报 `E0102` 并附带针对性提示：

```
%                     取余
& |                   单个符号；若要表示"并且/或者"请写 && / ||
:                     不是语法符号；网址等含 : 的文本必须加引号
^ ~ ? @ \ ` '         其他
```

`[` `]` **已经是语法符号**：它用来取下标（`名字[0]`），不是保留符号。
但 Lemon **没有方括号形式的列表字面量**——列表一律用块式声明（见 §2.10）。

`.` 已可用于成员访问，但目前**只有错误值有字段**（见 §2.4）。
`#` 不在此列——它用于唯一的指令 `#incloud`（见 §1.9）。

### 1.8 标点

`(` `)` `{` `}` `,` `=` `;`

### 1.9 指令

`#` 只用于一条指令：`#incloud`。

```lemon
#incloud web             // 启用内置能力模块
#incloud 工具.lemon1           // 并入同目录的源文件
#incloud "工具.lemon1"         // 引号可有可无
#incloud 工具 // 也可以   // 行尾注释会被剥掉
```

- 必须写在**行首**（前面只允许空格 / 制表符）并**独占一行**；写在行内报 `E0107`。
- 参数一直取到行尾。**只有「空白 + `//`」或「行首 `//`」**才算注释起点，
  因此 `lib//工具.lemon1` 会被当成完整路径而不是"路径 + 注释"。
- 参数外层成对的 `"` 会被去掉。
- 参数为空报 `E0107`；写成 `#include` 等别的名字同样报 `E0107`，并提示正确拼写。
- 认指令的是**词法器**，所以字符串与注释里的 `#incloud` 只是普通文本。
- 指令不产生语法树节点：它在词法之前就被加载器（`src/lang/include.ts`）消费掉了，
  因此 `lemon eval` 与 REPL 里没有文件上下文，用它会报 `E0207`。

## 2. 语法

### 2.1 EBNF

```
program        := '__init__' '{' initStmt* '}'
initStmt       := varDecl | listDecl | listOp | fileRead | fileSave | funcDecl | mainDecl | websetsDecl | gameDecl | classDecl | assignStmt | outputStmt | fileskillStmt | ifStmt | cycleStmt | breakStmt | tryStmt | exprStmt
varDecl        := ('int' | 'double' | 'text' | 'bool') IDENT '=' expr
listDecl       := 'list' '(' ('name' '=')? listTarget ')' (block | ε)
listTarget     := INT | IDENT
listRef        := 'list' '(' listTarget ')'
listOp         := 'add' '[' expr ']' 'to' listRef
                | 'del' '[' expr ']' 'to' listRef
                | 'del' listRef
                | 'file' listRef
                | 'clear' listRef
fileRead       := 'read' '{' fileLine* '}'
fileSave       := 'save' '{' fileLine* '}'
fileLine       := 'name' '=' expr
                | 'according' '=' expr
                | 'read' 'in' ('list' '(' listTarget ')' | 'say' | 'answer')
                | 'save' 'in' 'list' '(' listTarget ')'
funcDecl       := 'def' IDENT '(' params? ')' funcBody
mainDecl       := 'main' '(' ')' funcBody
funcBody       := '{' blockStmt* '}'
params         := IDENT (',' IDENT)*
ifStmt         := 'if' expr block ('elif' expr block)* ('else' block)?
cycleStmt      := 'cycle' '(' expr? ')' block
breakStmt      := 'break'
block          := '{' blockStmt* '}'
blockStmt      := varDecl | classVarDecl | listDecl | listOp | fileRead | fileSave | assignStmt | outputStmt | fileskillStmt | ifStmt | cycleStmt | breakStmt | returnStmt | tryStmt | exprStmt
returnStmt     := 'return' expr?
exprStmt       := expr
expr           := or
or             := and ('||' and)*
and            := comparison ('&&' comparison)*
comparison     := additive (('==' | '!=' | '<' | '<=' | '>' | '>=') additive)*
additive       := multiplicative (('+' | '-') multiplicative)*
multiplicative := unary (('*' | '/') unary)*
unary          := ('-' | '+' | '!') unary | power
power          := postfix ('**' unary)?
postfix        := callExpr (('.' IDENT callSuffix?) | ('[' expr ']'))*
                   // 点号后跟 '(' 即方法调用 对象.方法(实参...)
callExpr       := primary callSuffix?
callSuffix     := '(' (expr (',' expr)*)? ')'
primary        := INT | DOUBLE | TEXT | COLOR | 'true' | 'false' | IDENT | listRef | '(' expr ')'
COLOR          := '#rrggbb' | '#rgb'        // 颜色字面量，语义上就是文本
tryStmt        := 'try' block 'catch' '(' IDENT ')' block
websetsDecl    := 'websets' '(' ')' '{' webInit? '}'
webInit        := 'web' '.' 'init' '(' ')' '{' webElement* '}'
webElement     := webButton | webDiv | webText
webButton      := 'button' '{' ('to' expr)? '}'
webDiv         := 'div' webProps? '{' webElement* '}'
webProps       := '(' webProp (';' webProp)* ')'
webProp        := 'in' '(' expr ',' expr ';' expr ',' expr ')' | 'color' '=' expr
webText        := expr                      // 裸文本 / 字符串 / 变量，求值后按 text 渲染
gameDecl       := 'game' '(' ')' '{' gameInit? '}'
gameInit       := 'game' '.' 'init' '(' ')' '{' gameElement* '}'
gameElement    := displayWin | displayHead
displayWin     := 'display' '.' 'win' '(' expr ',' expr ')'
displayHead    := 'display' '.' 'head' '(' expr ')'
assignStmt     := IDENT '.' IDENT '=' expr
classDecl      := 'class' IDENT '{' classMember* '}'
classMember    := fieldDecl | methodDecl
fieldDecl      := ('int' | 'double' | 'text' | 'bool') IDENT
methodDecl     := 'def' IDENT '(' params? ')' '{' blockStmt* '}'
classVarDecl   := IDENT IDENT '=' expr
outputStmt     := 'output' expr
fileskillStmt  := cdStmt | runningStmt | deleteStmt
cdStmt         := 'cd' expr block
runningStmt    := 'running' expr
deleteStmt     := 'delete' expr
```

`websets` / `web.init` / `button` / `to` / `div` / `in` / `color` 都是**上下文关键字**：
只有出现在上面这几个位置时才具有特殊含义。因此 `say(button)`、`int websets = 1` 仍然照常工作（见 §6.5）。
`game` / `display.win` / `display.head` 同理（见 §6.6）。
`cd` / `running` / `delete` 同理（见 §6.8）。
`list` / `add` / `del` / `file` / `clear` 同理（见 §2.10）。

要点：

- `__init__` **必须存在且只能出现一次**，程序里不允许出现 `__init__` 之外的内容。
- `main()` 必须存在且只能声明一次，**不能带参数**，也**不写 `def`**。
- `def` 只允许出现在 `__init__` 顶层；在函数体内再定义函数报 `E0305`。
- 语句块（函数体、`if` 分支、`try` / `catch`）里只允许变量声明、`if`、`try` 与调用语句。
- `#incloud` 指令**不进入语法树**：它在词法之前就被加载器消费掉了（见 §6）。

### 2.2 语句与表达式

- **语句**：变量声明、函数声明、`main` 声明、`if` 语句、`cycle` 语句、`break`、`try` 语句、表达式语句。
- 表达式语句**必须是一条函数调用**。`1`、`你好` 这类裸表达式不能独立成句（`E0304`）。
- 表达式可以是：字面量（含 `true` / `false`）、名字、函数调用、一元/二元运算、括号分组。
- 括号不产生 AST 节点，仅用于改变结合方式。
- 运算出现的任何位置都可以是完整的表达式，包括函数实参：`say(1 + 2 * 3)`。

### 2.3 try / catch

```lemon
try {
    say(7 / zero)
} catch (错误) {
    say(错误)
    say(错误.code)
}
```

- `try` 块**必须**紧跟一个 `catch`；缺了报 `E0202`。
- `catch` 后面必须写 `(名字)`，这个名字绑定捕获到的**错误值**。
- 两个块各自是**独立作用域**：`try` 里声明的变量在 `catch` 里看不到，反之亦然；
  外层变量在两个块里都能用。
- 可以嵌套，也能出现在 `__init__` 顶层或函数体内。

**能捕获什么**：`try` 块内（含其间调用的函数）抛出的**运行期错误**——
除零 `E0405`、整数溢出 `E0406`、负指数 `E0407`、非有限结果 `E0408`、调用层数过深 `E0403` 等。

**捕获不到什么**：词法、语法与静态检查错误（`E01xx` / `E02xx` / `E03xx`）。
这些错误在程序开始执行前就已经中止了流程，`try` 根本没有机会运行。

`catch` 块里再次抛出的错误会继续向外传播（可以被外层 `try` 捕获）。

### 2.4 成员访问

目前只有**错误值**有字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `code` | `text` | 错误码，如 `E0405` |
| `line` | `int` | 出错行号 |
| `message` | `text` | 说明文字（不含错误码） |

```lemon
} catch (错误) {
    say(错误)              // E0405 除数为 0，无法计算
    say(错误.code)         // E0405
    say(错误.line)         // 6
    say(错误.message)      // 除数为 0，无法计算
}
```

对非错误值取字段报 `E0317`（`text name = Lemon` 后写 `name.code`）。
取错误值上不存在的字段同样报 `E0317`。

错误值**不能存进变量**（`text t = 错误` 报 `E0307`），但可以作为实参传给函数
（参数类型是 `any`），在函数里继续读它的字段。

### 2.5 if / elif / else

```lemon
if 分数 >= 90 {
    say("优秀")
} elif 分数 >= 60 {
    say("及格")
} else {
    say("不及格")
}
```

- 条件**不写括号**（与 `try` / `catch` 风格一致），直接跟表达式，例如 `if a > 0 {`。
  想加括号也可以：`if (a > 0) {` —— 括号只是分组，不产生额外节点。
- 条件**类型必须是 `bool`**，否则报 `E0318`。因此 `if a {`（`a` 是 `int`）会报错，
  要写 `if a != 0 {`；`if say(1) {` 同样报 `E0318`（`say` 没有返回值）。
- `elif` 可以出现任意多次；`else` 至多一次且必须是最后一支。
  `else` 后面**不能再跟条件**（写成 `else b {` 报 `E0202`）。
- 分支体各自是**独立作用域**（与 `try` / `catch` 一致）：里面声明的变量不会泄漏到
  其他分支或外层，但可以遮蔽外层的同名变量。
- 执行时**按顺序求值条件，命中第一个为 `true` 的分支后执行并结束**；
  没命中的条件不会被求值，因此条件里不要写有副作用的调用。
- 条件都不成立且没有 `else` 时，什么都不做。
- 可以嵌套，也可以出现在 `__init__` 顶层、函数体内、`try` / `catch` 块内。

```lemon
if a > 0 && a < 10 {      // 用 && 组合多个条件
    say("一位数")
}

if 名字 != 小明 {           // 文本比较用 == / !=
    say("不是他")
}

if !已登录 {                // ! 只能作用于 bool
    say("请先登录")
}
```

> 把 `==` 误写成 `=` 时会得到专门的提示：
> `if a = 1 {` → `E0202` + 提示「判断相等要写 ==（单个 = 只用在变量声明里）」。

### 2.6 cycle 循环与 break

```lemon
cycle(3) {          // 重复 3 次，体内 i 依次是 0 1 2
    say(i)
}

cycle() {           // 没有次数：无限循环，i 一直递增
    if i >= 5 {
        break       // 跳出最内层的 cycle
    }
    say(i)
}
```

- 形状与 `main() { ... }` 一致：`cycle` + 括号 + 块，因此不需要记一套新语法。
- **次数必须是 `int`**，否则报 `E0319`；`cycle(1.5)`、`cycle(你好)`、`cycle(say(1))` 都会在运行前被拦下。
- **次数不能为负**：字面量负数报 `E0320`（运行前），算出来的负数报 `E0409`（运行期）。
  `cycle(0)` 合法，表示一轮都不执行。
- **轮次变量 `i`**：`cycle(N)` 里依次是 `0 .. N-1`；`cycle()` 里从 0 开始一直递增。
  它和函数参数一样会**遮蔽**外层的同名变量，循环之外恢复原值。
- **循环体每轮都是全新作用域**：体内声明的变量不会带到下一轮，也不会泄漏到循环之外。
- `break` **只能出现在 `cycle` 体内**，否则报 `E0203`（解析阶段）。
  它只跳出**最内层**的那个 `cycle`；嵌套时外层继续执行。
- `break` 写在 `try` 块里**不会被 `catch` 吃掉**——它不是错误，只是一条跳出循环的捷径。
- 可以嵌套，也能出现在 `__init__` 顶层、函数体、`if` 分支、`try` / `catch` 块内。

```lemon
// 常见的"最多试 N 次，满足条件就提前收工"
cycle(5) {
    if i * i > 10 {
        break
    }
    say(i)
}

// 体内声明 i 会与轮次变量冲突（E0306）
cycle(2) {
    int i = 5        // ❌ E0306：变量 i 在该作用域内重复声明
}
```

> 对照：`cycle(N) { ... }` ≈ `for i in range(N)`；`cycle() { ... }` ≈ `while true`（靠 `break` 结束）。
> `while` / `for` / `continue` 尚未实现，写出来会得到明确的"暂不支持"提示。

### 2.7 函数声明

```lemon
def greet(who) {
    say("你好")
    say(who)
}
```

- 参数**不写类型**，静态检查中其类型为 `any`（任何值都可传入）。
- 参数名不能是内置函数名（`E0306`）。
- 参数名不能重复（`E0314`）。
- 函数的返回值由 `return` 给（见 §2.11）。**没有 `return` 的函数调用结果是 `unit`**，
  即 `def` 只描述副作用，与以前完全一样——既有程序不受影响。

### 2.8 语句分隔

**分号可写可不写，靠换行断句。**

- 一条语句结束后，若下一个 Token 出现在**后续行**，则语句自然结束。
- 若没有写 `;`，而下一个 Token 仍在**同一行**，报 `E0206` 并提示「写在同一行时需要用 ; 分隔」。
- 允许连续分号 `;;`。
- 调用实参可以换行书写：

```lemon
say(
    你好
)
```

### 2.9 注释与缩进

注释可在任意 Token 之间出现。缩进没有任何语法含义。
`} elif ... {` 与 `} else {` 可以紧跟在上一分支的 `}` 之后，也可以另起一行。

**全角符号**：`（` `）` `｛` `｝` `；` 不能当语法符号用，出现即报 `E0102` 并提示改成半角。
全角逗号 `，` 与冒号 `：` 例外——它们是中文裸文本的常见内容，仍照常算文本的一部分
（`say("你好，世界")` 合法）。

### 2.10 列表

列表有两种，**操作它们的语法完全一样**：

```lemon
list(分数) {          // 命名列表：就是一个普通变量
    90
    85
}

add list(1)           // 编号槽：全局容器，按编号访问
add[90] to list(1)
```

| | 编号槽 `list(1)` | 命名列表 `list(分数)` |
| --- | --- | --- |
| 身份 | 全局编号容器，**用到就存在**，没有"未声明"一说 | 普通变量，作用域与 `int a = 1` 完全相同 |
| 声明 | `add list(1)` 或 `list(1) { 元素 }` | `list(分数) { 元素 }` |
| 引用 | `list(1)` | `list(分数)`，与直接写 `分数` 等价 |
| 再次声明 | 是**初始化**（覆盖原有内容） | 报 `E0306`（同名变量重复声明） |

`list(X)` 是个普通的**表达式**，所以两种列表都能取值、传参、嵌套：

```lemon
say(list(1))         // [90, 85]
say(len(list(1)))    // 2
say(list(1)[0])      // 90
```

**声明**

- 目标是**整数编号**或**标识符**，也可以是 `list(name = 目标)`——只是把"这个位置
  放的是列表名"写明白。目标是别的（`list(true)`、`list(1.5)`）报 `E0205`；
  写在 `add list(...)` 位置时报 `E0326`。
- `{}` 里**一行一个元素**，元素是任意表达式，按书写顺序求值；同一行写多个要用 `;` 分隔
  （与语句的换行断句规则一致，见 §2.8）。
- 元素类型**不要求一致**，空列表也合法。
- **声明就是初始化**：同一个编号或名字再声明一次会**覆盖**原有内容，而不是追加。
- 写在同一行时 `list(X) { ... }` 与 `add list(X)` 的区别只是后者不写花括号。

**四个操作**

```lemon
add[元素] to list(X)     // 往末尾追加一个元素
del[元素] to list(X)     // 删掉第一个与它相等的元素；找不到报 E0416
del list(X)              // 删掉整个列表（只能用于编号槽，见下）
file list(X)             // 一行一个元素，全部输出
clear list(X)            // 清空内容（列表本身还在，还能继续 add）
```

- `add` / `del` / `file` / `clear` 都是**上下文关键字**：只有后面紧跟 `[` 或 `list (` 时
  才成立。因此 `int add = 1`、`say(file)` 这些既有写法照常工作（与 §6.6 同一条思路）。
- `add` 与 `del` 各有两种形态，靠关键字后面跟的是 `[` 还是 `list (` 区分：
  `add list(X)` 建列表 / `add[元素] to list(X)` 加元素；
  `del list(X)` 删掉整个列表 / `del[元素] to list(X)` 删一个元素。
- `del[元素]` 的相等判定与 `==` 一致：`1` 与 `1.0` 算相等；列表这类复合值按**引用**比较。
  找不到就**报错**而不是静默跳过——写错值能立刻发现。
- `file` 与 `say(列表)` 的输出刻意不同：`file` 一个元素一行，`say` 输出 `[90, 85]`。
- `add list(X)` 是"建一个空列表"，等价于 `list(X) {}`。

**`del list(X)` 的语义**

- **只能删编号槽**。命名列表是普通变量，语言里没有"取消声明"这回事，删掉绑定就会
  出现"静态检查认为它还在、运行期却找不到"的裂缝，所以直接拦下报 `E0330`：
  要清空用 `clear list(名字)`，要让它彻底消失就把它声明在更小的作用域里。
- 删掉之后 `list(X)` 依然可用——编号槽"用到就存在"，这时是一个**新的空槽**。
- 删一个本来就不存在的槽**不报错**（不存在"未声明"这种状态）。
- 别处已经持有的那个列表**不会被删掉**：删的只是"编号 → 列表"这条绑定，
  值本身还活着（引用语义，与上面"可变与引用语义"一节一致）。

**可变与引用语义**

列表是**可变**的：`add` / `del` / `clear` 改的就是那个列表本身。因此指向同一个列表的
两个名字会一起变：

```lemon
list(1) { 1 }
list(别名) { list(1) }
add[2] to list(1)
say(别名)            // [1, 2] —— 别名看到的是同一个列表
```

编号槽存在**全局**：在函数体里 `add[7] to list(5)` 建的槽，函数返回之后依然在，
函数外也能读到。命名列表则遵守普通变量的作用域规则。

**下标与长度**

- 下标从 **0** 开始，必须是 `int`，否则报 `E0307`。
- **没有负数下标**：`名单[0 - 1]` 与 `名单[99]` 一样报 `E0415`。
- 越界是**运行期**错误（静态只知道类型、不知道长度），可以被 `try` / `catch` 捕获。
- 对不是列表的值取下标报 `E0327`。
- `len(列表)` → `int`，元素个数；参数不是列表报 `E0307`。

**没有方括号形式的列表字面量。** `[` `]` 只出现在两个地方：取下标（`名字[0]`），
以及 `add[X]` / `del[X]` 的元素位置。写 `[1, 2, 3]` 报 `E0201` 并提示改用块式声明。

**类型**：列表的类型是 `list`，元素的静态类型一律记作 `any`（元素类型可以混），
因此 `名单[0]` 的类型也是 `any`——具体是什么值由运行期决定，与函数参数（§2.7）同一条思路。
`list(X)` 引用的静态类型就是 `list`。

**输出**：`say(列表)` 输出 `[元素, 元素, ...]`，元素用各自的正常形式（文本不加引号），
嵌套列表递归展开。

```lemon
say(分数)     // [90, 85]
say(嵌套)     // [[1, 2], [1, 2]]
```

### 2.11 文件读写 read / save

`read{...}` 与 `save{...}` 是两个**语句块**，用于读写磁盘上的文本文件。它们是
`read` / `save` 作**上下文关键字**（只有紧跟 `{` 才成立，所以 `text read = 1`、
`text save = 1` 依旧照常工作）。

```lemon
read {
    name = "1.txt"          // 文件名（字符串表达式，可用变量；缺省报 E0331）
    according = "utf-8"     // 编码，可省略，默认 utf-8
    read in list(1)         // 把每一行作为一个文本元素存进 list(1)
    read in say             // 同时把内容原样打印出来
    read in answer          // （可选）交互式选段：运行时在终端问"读哪一部分"
}

save {
    name = "1.txt"
    according = "utf-8"
    save in list(1)         // 把 list(1) 每个元素写一行（覆盖写）
}
```

要点：

- **一次读取，多处落点**：`read in list(X)` 与 `read in say` 可同时写——文件只 IO 一次，
  结果按落点扇出。至少得有一个落点，否则报 `E0332`（`read in answer` 只是"选段开关"，
  本身不决定内容去哪）。
- **`read in answer` 交互式选段**：运行时在终端弹问"要读哪一部分？"，用户输行号即可，
  支持 `3`、`3-7`、`3,5,7`、`3-7,9` 任意组合；越界与格式错误的部分直接忽略。
  它**需要真实终端**——管道 / 重定向下拿不到输入，报 `E0410`（与 `keyboard` / `waitKey` 同一条语义）。
- **行模型与列表完全对称**：`read in list(X)` 把每行读成一个文本元素，`save in list(X)`
  把每个元素写一行，`file list(X)` 也是一行一个元素——三者互为可逆，读回来能原样还原。
- **编码**：默认 `utf-8`；其它编码原样透传给宿主文件系统，不支持时读会报 `E0903`。
  读取时自动去掉 UTF-8 BOM，避免它混进第一行。
- **路径**：相对路径以**运行命令时的目录**为基准（不是 `.lemon1` 文件所在目录）。
  读不到文件报 `E0902`；写失败（权限 / 磁盘满）报 `E0904`。
- **`save` 覆盖写**（不追加）；落点列表必须存在且是列表，否则静态检查报 `E0334`。

### 2.12 return

```lemon
def 加(a, b) {
    return a + b
}

def 绝对值(x) {
    if x < 0 {
        return 0 - x
    }
    return x
}
```

- 值的**可选**：`return 表达式` 带值返回；光秃秃的 `return` 表示提前收工。
- 它是一条**语句**，不是表达式。所以 `int a = return 1` 在语法层就不成立（`E0201`），
  不用在类型检查里再兜一遍。
- 表达式必须与 `return` 写在**同一行**（与全局的换行断句规则一致，见 §2.8）：

```lemon
def f() {
    return
    1            // ❌ 这是另一条语句，会被当成孤立的表达式（E0304）
}
```

- 只能写在**函数体内**；写在 `__init__` 顶层报 `E0204`（那里没有可返回的地方）。
- **`main()` 里不能带值返回**（`E0328`）——main 是程序入口，返回值没有人接。
  `main()` 里的裸 `return` 合法，含义是**提前结束程序**：

```lemon
main() {
    say("先说话")
    return              // 后面的语句不再执行
    say("不会输出")
}
```

- `return` **不是错误**，所以 `try / catch` 抓不到它。下例里成功的除法会把结果
  带出去，只有真正除零时才走 `catch`，而 `catch` 里的 `return` 同样能带出值：

```lemon
def 安全除(a, b) {
    try {
        return a / b
    } catch (错误) {
        return 错误.code
    }
}
```

- 写在 `cycle` 里会**跳出整个函数**（不只是跳出循环），与 `break` 的区别就在这里。

**返回类型怎么定**：参数不写类型，返回类型也就没法写死。规则只有一句——
**函数体里出现带值的 `return`，调用结果就是 `any`；没有就是 `unit`**。

```lemon
def f() { return 你好 }        // 调用结果是 any
def g() { say(1) }            // 调用结果是 unit

int a = f()      // ✅ 静态通过；f 是 any，具体对不对要到运行期（这里会报 E0402）
int b = g()      // ❌ E0307：unit（无值）不能赋给 int
```

`any` 与函数参数完全同级：参与运算、赋值、比较都照常。想让静态检查帮上更多忙，
就让返回值尽量落在同一个具体类型上——不过因为参数本身就是 `any`，
`return a + b` 这类写法推不出具体类型，必然还是 `any`。

## 3. 静态检查

执行任何代码之前，先按词法 → 语法 → 静态检查的顺序完成检查；**有任何错误都不执行程序**。

### 3.1 名字的可见性

| 位置 | 可见的名字 |
| --- | --- |
| `__init__` 顶层语句 | 内建函数 + 已声明的**函数**（提升）+ **本行之前**已声明的顶层变量 |
| 函数体内 | 内建函数 + 全部函数 + **全部顶层变量** + 自身参数 + 自身局部变量 |
| 块内（`if` 分支 / `try` / `catch` / `cycle` 循环体） | 上述全部 + 该块内已声明的变量（`cycle` 另有轮次变量 `i`） |

块与函数参数一样会**遮蔽**外层的同名名字，且块内声明不会泄漏到块外。

函数体内可以看到任意位置的顶层变量，因为 `main()` 一定在所有顶层语句执行完之后才被调用。

### 3.2 函数提升

所有 `def`（含 `main`）与声明顺序无关，任意位置都能调用：

```lemon
__init__ {
    main() { later(1) }      // 合法：later 已提升
    def later(x) { say(x) }
}
```

### 3.3 类型规则

五种类型：`int`、`double`、`text`、`bool`、`list`，另有 `unit`（无值）与 `any`（通配）。

`list` 没有对应的类型关键字——列表只能用 `list(名字) { ... }` 声明出来，
不能写成 `list a = ...`（那会被当成列表声明，然后因缺少 `= 名字` 而报错）。
元素与下标的静态类型统一是 `any`，可赋值性按上表照常推导。

可赋值性 `assignable(from, to)`：

| from | to | 结果 |
| --- | --- | --- |
| 任意 | `any` | ✅ |
| `any` | 任意 | ✅ |
| 相同类型 | 相同类型 | ✅ |
| `int` | `double` | ✅ 隐式提升 |
| 其他组合 | | ❌ `E0307` |

```lemon
int a = 1        // ✅
double b = 1     // ✅ 提升为 1.0
double c = 1.23  // ✅
text d = 你好     // ✅
bool e = true    // ✅
bool f = a > 0   // ✅ 比较的结果就是 bool
int g = 你好      // ❌ E0307
int h = 1.5      // ❌ E0307（不支持取整转换）
int i = true     // ❌ E0307（bool 与数字互不相通）
bool j = 1       // ❌ E0307
```

**运算结果的类型**（记为 `promote(a, b)`：只要有一侧是 `double` 就得 `double`）：

| 左 | 运算符 | 右 | 结果 | 说明 |
| --- | --- | --- | --- | --- |
| `int` | `+ - * /` | `int` | `int` | `/` 向零截断 |
| `double` | `+ - * /` | `int` 或 `double` | `double` | 含 `int` 时先提升 |
| `text` | `+` | `text` | `text` | 拼接 |
| `text` | `+ - * /` | 数字 | ❌ `E0307` | 提示「文本只能与文本用 + 拼接」 |
| 数字 | `+` | `text` | ❌ `E0307` | 同上 |
| `text` | `- * /` | `text` | ❌ `E0307` | 同上 |
| `unit` | 任意 | 任意 | ❌ `E0307` | `say(...)` 没有返回值 |
| `int` | `-x` / `+x`（一元） | — | `int` | 保持操作数类型 |
| `double` | `-x` / `+x`（一元） | — | `double` | 保持操作数类型 |
| `text` | `-x` / `+x`（一元） | — | ❌ `E0307` | 只有 int / double 能用一元正负号 |
| `int` | `**` | `int` | `int` | 指数必须是**非负整数**，否则报错 |
| 数字 | `**` | 数字（含 `double`） | `double` | 只要有一侧是 `double` 就走浮点乘方 |
| `error` | `.code` / `.message` | — | `text` | 错误值的字段 |
| `error` | `.line` | — | `int` | 错误值的字段 |
| 非 `error` | `.字段` | — | ❌ `E0317` | 目前只有错误值有字段 |

**比较运算**（结果类型固定为 `bool`）：

| 左 | 运算符 | 右 | 结果 | 说明 |
| --- | --- | --- | --- | --- |
| 数字 | `==` `!=` `<` `<=` `>` `>=` | 数字 | `bool` | `int` 与 `double` 混用也可，按数值比较（`1 == 1.0` 为 `true`） |
| `text` | `==` `!=` | `text` | `bool` | 文本相等性 |
| `text` | `<` `<=` `>` `>=` | `text` | ❌ `E0307` | 文本没有全序，不支持大小比较 |
| `bool` | `==` `!=` | `bool` | `bool` | |
| `bool` | `<` `<=` `>` `>=` | `bool` | ❌ `E0307` | |
| 跨类型 | 任意比较 | 跨类型 | ❌ `E0307` | 例如 `1 == 你好`、`true == 1` |
| `unit` | 任意比较 | 任意 | ❌ `E0307` | `say(...)` 没有返回值 |
| `any` | 任意比较 | 任意 | `bool` | 参数类型未知，交给运行期判断 |

**逻辑运算**（两侧都必须是 `bool`，结果 `bool`）：

| 左 | 运算符 | 右 | 结果 | 说明 |
| --- | --- | --- | --- | --- |
| `bool` | `&&` `\|\|` | `bool` | `bool` | **短路**：左侧已能定下结果时右侧不求值 |
| 非 `bool` | `&&` `\|\|` | 任意 | ❌ `E0307` | 提示"数字没有真假之分"等 |
| `bool` | `!x`（一元） | — | `bool` | |
| 非 `bool` | `!x`（一元） | — | ❌ `E0307` | `!1` 报错，要写 `!(a > 0)` |

`error`（错误值）**没有对应的类型关键字**：它只由 `catch (名字)` 绑定产生，
不能声明成变量类型，但可以传给参数（参数是 `any`）。

**乘方的额外规则**：

- `int ** int` 的结果必须是整数：指数为负时报错（字面量在运行前报 `E0316`，算出来的报 `E0407`）。
  要负数指数请把底数写成小数：`2.0 ** -1` 得 `0.5`。
- `int` 乘方结果超出安全整数范围报 `E0406`，例如 `2 ** 100`。
- `double` 乘方结果不是有限数报 `E0408`，例如 `(0.0 - 8.0) ** 0.5`（负数开偶次方根）
  或 `2.0 ** 10000`（溢出）。

`any`（函数参数的类型）参与运算时结果记为 `any`，不做静态判断，交由运行期决定：

```lemon
__init__ {
    def twice(x) { say(x * 2) }   // ✅ 合法：x 是 any
    main() { twice(3) }           // 运行期 3 * 2 = 6
}
```

除数为**字面量 0** 时在运行前报 `E0315`；除数运行期才确定为 0 时报 `E0405`。

```lemon
say(7 / 0)          // ❌ E0315（编译期）
int d = 1 - 1
say(7 / d)          // ❌ E0405（运行期）
```

### 3.4 裸文本的判定

标识符的最终身份由静态检查决定，规则按优先级如下：

1. **能查到名字**（变量 / 函数 / 内建 / 参数）→ 按该名字解释。
2. **解析不到，且该名字是「声明在后面的顶层变量」** → 报 `E0312`（顶层语句从上到下执行）。
3. **解析不到，但与某个已声明的名字编辑距离为 1**（仅 ASCII 名字、长度 ≥ 3）→ 报 `E0312` 并提示是否想用某个名字。
   - 该启发式只对**长度 ≥ 3 的 ASCII 名字**生效，因此 `text t = bay` 这类裸文本不会被误报。
   - 在**调用位置**上比对时会额外纳入内置函数名，因此 `sya(你好)` 会提示「是否想调用 say」。
4. **其余情况** → 视为**裸文本字面量**（但在 `say` 实参位置要加引号，报 `E0344`，见 §1）。

```lemon
__init__ {
    int count = 1
    main() {
        text 甲 = countt   // ❌ E0312：是否想使用已声明的 count？
        text 乙 = 你好     // ✅ 裸文本
        text 丙 = bay      // ✅ 裸文本（与 say 形近但不报错，因为不在调用位置）
    }
}
```

### 3.5 名字冲突

内置函数名（`say` / `ask` / `keyboard` / `waitKey` / `sleep` / `len`）**不可被任何声明占用**（变量、函数、参数均报 `E0306`）。

| 冲突 | 错误码 |
| --- | --- |
| 顶层变量重复声明 | `E0306` |
| 函数体内同作用域重复声明变量 | `E0306` |
| 变量名与函数名相同 | `E0306` |
| 函数重复声明 | `E0306` |
| `main` 重复声明 | `E0306` |
| 占用内置名 | `E0306` |

发生冲突时，检查器会跳过该声明并继续检查其余代码，**不会产生级联错误**。

### 3.6 调用检查

| 情形 | 错误码 |
| --- | --- |
| 调用未定义的函数 | `E0308` |
| 把变量当函数调用 | `E0309` |
| 函数实参个数不符 | `E0310` |
| `say` 实参个数不是 1 | `E0311` |

### 3.7 其他检查

| 情形 | 错误码 |
| --- | --- |
| 缺少 `__init__` | `E0301` |
| `__init__` 出现多次 | `E0302` |
| 缺少 `main()` | `E0303` |
| 裸表达式独立成句 | `E0304` |
| 函数内定义函数 | `E0305` |
| `main` 带参数 | `E0313` |
| 参数名重复 | `E0314` |
| `if` / `elif` 的条件不是 `bool` | `E0318` |
| `cycle` 的次数不是 `int` | `E0319` |
| `cycle` 的次数是字面量负数 | `E0320` |
| `main()` 里带值返回 | `E0328` |
| `break` 不在 `cycle` 循环体内 | `E0203`（解析阶段） |
| `return` 不在函数体内 | `E0204`（解析阶段） |

`E0318` 的提示会按实际类型给出改法：

```lemon
if a { ... }        // ❌ E0318 → 比较运算的结果就是 bool，例如：if a > 0 { ... }；判断非 0 请写 a != 0
if 名字 { ... }      // ❌ E0318 → 文本不能直接作条件；请先比较，例如：if name != "" { ... }
if say(1) { ... }   // ❌ E0318 → say(...) 没有返回值，不能作为条件
```

条件里如果**已经有别的错误**（例如名字打错触发了 `E0312`），就只报那一个，不再补 `E0318`。

`lemon check --warn-unused` 会额外把「声明后从未使用」的顶层变量与函数报告为**警告**
（默认关闭，避免干扰）。

## 4. 运行时语义

### 4.1 执行顺序

1. 登记全部 `def` 与 `main`（函数提升）；
2. 按源码顺序执行 `__init__` 的顶层语句（跳过声明）；
3. 调用 `main()`。

### 4.2 值

| 值 | 说明 |
| --- | --- |
| `int` | 整数 |
| `double` | 双精度浮点 |
| `text` | 文本 |
| `bool` | 真假值 |
| `error` | 错误值：`code` + `line` + `message`，由 `catch` 绑定产生 |
| `unit` | 无值（函数调用的结果） |
| `func` | 函数（不可作为值传递） |

### 4.3 输出格式

`say(x)` 输出 `x` 后追加换行：

| 输入值 | 输出 |
| --- | --- |
| `int 3` | `3` |
| `double 12.5` | `12.5` |
| `double 2`（整数值） | `2.0` |
| `double 1e21` | `1e+21`（科学计数法不再追加 `.0`） |
| `text 你好` | `你好` |
| `bool true` / `bool false` | `true` / `false` |
| `list [1, 2, 3]` | `[1, 2, 3]`（元素用各自的形式，文本不加引号） |
| `list []`（空列表） | `[]` |

### 4.4 作用域与遮蔽

- 函数调用时的环境链为：函数局部作用域 → 声明该函数时的环境。
- 参数可以遮蔽同名的顶层变量；函数内的局部变量不会泄漏到顶层
  （在顶层引用同名名字会按 §3.4 降级为裸文本）。
- `try` / `catch` 块、`if` 分支体、`cycle` 循环体各自再套一层作用域：里面声明的变量
  不泄漏到外层，但可以遮蔽外层的同名变量。
- `cycle` 的轮次变量 `i` 也同样遮蔽外层；循环体每轮都用**全新的作用域**，
  因此上一轮声明的变量不会留到下一轮。
- 递归现在可以正常收敛——用 `if` 写终止条件不会增长调用深度：

```lemon
def 倒数(n) {
    say(n)
    if n > 1 {
        倒数(n - 1)
    }
}
```

### 4.5 运行期错误

| 情形 | 错误码 |
| --- | --- |
| 变量在运行到该语句时还没有值 | `E0401` |
| 运行期类型不匹配（静态检查的兜底） | `E0402` |
| 调用层数超过 200 层 | `E0403` |
| 未预期的内部错误 | `E0404` |
| 除数为 0 | `E0405` |
| 整数运算结果超出安全范围 | `E0406` |
| `int` 乘方的指数为负 | `E0407` |
| 乘方结果不是有限数（NaN / Infinity） | `E0408` |
| `cycle` 的次数为负（算出来的） | `E0409` |

**除零**：`int` 与 `double` 的除数都不允许为 0（不做 IEEE 无穷大处理）。

**整数溢出**：`int` 运算结果必须落在 ±9007199254740991 内，否则报 `E0406`
（提示改用 `double`）。这样整数不会静默变成不精确的值。`double` 运算不做该检查。

**被捕获的错误**：出现在 `try` 块内的运行期错误会被 `catch` 接住，程序继续执行；
`catch` 块自身抛出的错误继续向外传播。未被任何 `try` 覆盖的错误则中止程序并以退出码 `1` 结束。

- 调用深度上限默认 **200**，可通过 API 的 `maxCallDepth` 调整。
- 宿主栈溢出（`RangeError`）会被转译为 `E0403`，**不会向用户暴露宿主堆栈**。
- 运行期错误会附带 Lemon 层调用栈（最外层在前）。
- **错误发生前已经产生的输出会保留**，程序输出（stdout）与错误信息（stderr）严格分流。

### 4.6 键盘输入

两个内置函数，返回类型不同、用途也不同：

| 函数 | 返回 | 行为 |
| --- | --- | --- |
| `keyboard(键名)` | `bool` | **非阻塞**：这个键自上次读取之后被按过就返回 `true`，并**立刻清零** |
| `waitKey(键名)` | `unit` | **阻塞**：停在调用处，直到该键被按下 |

```lemon
if keyboard(w) {          // 轮询：本轮循环有没有按 w
    say("前进")
}

waitKey(space)            // 等待：按空格之前不往下走
```

**判定语义是"按过就算"，不是"当前是否按住"**。终端只报告"按下了什么"，
拿不到"松开了"（没有 keyup 事件），因此：

- 一次按下只会产生**一个** `true`，被读取后清零；再读就是 `false`。
- 读取之前重复按同一个键**只算一次**（锁存，不是计数）。
- 想近似"按住"：在 `cycle()` 里持续轮询——键盘自动重复会不断把锁存重新置起，
  于是按住期间每圈都能读到 `true`。

**键名**：单个字符（`w`、`a`、`1`、`-`，大小写等价）或命名键
`space` / `enter` / `esc` / `up` / `down` / `left` / `right` / `tab` / `backspace`。
中文名也接受最常见的几个：`空格`、`回车`、`上`、`下`、`左`、`右`。

键名写成**字面量**时静态检查会校验拼写，不认识的键名报 `E0321` 并列出可用键名；
键名来自变量时只能在运行期报同一个错误。

```
keyboard(ww)      // ❌ E0321：keyboard 不认识键名「ww」
keyboard(空格)     // ✅ 等价于 keyboard(space)
```

**只能在真实终端里用**：管道输入、重定向、编辑器内运行、REPL 都拿不到终端键盘，
调用时报 `E0410`（退出码 1），**不会静默地一直返回 false**。

**Ctrl+C**：读取键盘时终端进入 raw 模式，Ctrl+C 不再产生 `SIGINT`，而是被键盘层
识别为中断信号——程序立即中止、终端状态恢复、退出码为 **130**。

`cycle()` 里轮询键盘是满速空转（会占满一个 CPU 核心）；用 `break` 及时退出循环。

`keyboard` / `waitKey` 也是**内置函数名**，不可被变量、函数、参数占用（`E0306`）。

### 4.7 时间与 sleep

| 函数 | 返回 | 行为 |
| --- | --- | --- |
| `sleep(秒数)` | `unit` | 暂停指定时间；**单位是秒**，可以是小数 |

```lemon
sleep(1)        // 1 秒
sleep(0.5)      // 半秒
sleep(1min)     // 一分钟（带单位的字面量）
sleep(500ms)    // 半秒
```

- 参数接受 `int` 与 `double`（`int` 按秒提升），不接受 `text` / `bool` / `unit`（`E0307`）。
- `sleep(0)` 合法，立即返回。
- **负数报 `E0412`**（`sleep(0 - 1)` 这种算出来的负数在运行期才发现）。
- 精度受系统定时器粒度影响，实测偏差约 15 毫秒量级。
- 长睡眠期间按 **Ctrl+C 也能立刻停下**——但只在程序确实用过 `keyboard` / `waitKey`
  时才会检查（否则不会为了睡觉把终端切进 raw 模式）。

`sleep` 也是**内置函数名**，不可被占用（`E0306`）。

典型用法是给 `cycle()` 限帧，避免满速空转占满 CPU：

```lemon
cycle() {
    if keyboard(q) {
        break
    }
    say("帧")
    sleep(20ms)      // 约 50 帧/秒
}
```

### 4.8 输入 ask 与分级输出 output

**`ask(提示词?)`** —— 向用户提问并读回一行文本，返回 `text`：

```lemon
text 名字 = ask(你叫什么名字？)
say(名字 + "，你好")
```

- 提示词可省略（`ask()` 只读取、不打印任何提示）；提示词是文本，可用引号或裸文本。
- 需要**真实终端**：REPL、管道 / 重定向下拿不到输入会报 `E0410`（与 `keyboard` 同一条语义）。
- `ask` 是内置函数名，不可被占用（`E0306`）。

**`output <文本>`** —— 带级别的输出语句。文本开头的 `[标记]` 决定级别与去向：

| 标记 | 去向 | 说明 |
| --- | --- | --- |
| `[error]` | stderr | 错误信息 |
| `[warning]` | stderr | 警告信息 |
| `[log]` / 无标记 | stdout | 普通日志 |

```lemon
output "[error]这是一个错误"     // → stderr
output "[warning]这是一个警告"   // → stderr
output "[log]这是一个日志"       // → stdout
output "没有标记也走 stdout"
```

- 标记**大小写不敏感**；只认 `error` / `warning` / `log`，其它 `[xxx]` 一律当普通日志。
- 标记**原样打印**（不剥离）。
- 文字必须是 `text`（否则 `E0307`），可以写在任何语句位置（函数体、`if` / `cycle` 块里）。
- 与 `say` 的区别：`say` 永远走 stdout，`output` 按首标记分流。

## 5. 命令行契约

### 5.1 子命令

| 命令 | 说明 |
| --- | --- |
| `lemon` | 进入 REPL |
| `lemon <文件.lemon1>` / `lemon run <文件.lemon1>` | 运行 |
| `lemon check [--json] [--stdin] [--warn-unused] <文件.lemon1>` | 只检查不执行 |
| `lemon eval "<代码>"` | 把代码片段包进 `main()` 后求值，报错行号与输入对齐 |
| `lemon ast <文件.lemon1>` | 打印语法树（静态检查后，名字会标注为 变量/函数/内置/裸文本） |
| `lemon tokens <文件.lemon1>` | 打印词法单元表 |
| `lemon help` / `lemon --help` | 帮助 |
| `lemon version` / `lemon --version` | 版本 |

`#incloud` 只在**从文件运行时**生效（`run` / `check` / `ast`）；`eval` 与 REPL 没有文件
上下文，用到它会报 `E0207`。`tokens` 是词法层的调试视图，会原样打印 `Directive` 单元。

### 5.2 退出码

| 码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 语言错误（词法 / 语法 / 静态检查 / 运行期） |
| `2` | 用法错误（文件不存在、参数不合法、未知选项） |
| `130` | 运行中被 Ctrl+C 中断（读取键盘时终端处于 raw 模式，没有 SIGINT） |

### 5.3 `check --json` 输出契约

**该格式被编辑器插件依赖，视为对外稳定契约。**

成功（stdout 上只有这一行 JSON）：

```json
{"ok":true,"diagnostics":[]}
```

失败：

```json
{
  "ok": false,
  "diagnostics": [
    {
      "severity": "error",
      "code": "E0307",
      "message": "类型不匹配：text（文本）的值不能赋给int（整数）变量 a",
      "line": 4,
      "col": 17,
      "endLine": 4,
      "endCol": 20,
      "hint": "若想保存文字，请把类型改为：text a = ..."
    }
  ]
}
```

- `line` / `col` / `endLine` / `endCol` 均从 **1** 开始，`col` 以 UTF-16 code unit 计（与编辑器一致）。
- `endCol` 为**不含**结束位置。
- `hint` 可能缺失。
- 文件不存在时同样输出合法 JSON（`ok:false`，`code:"E0902"`），但退出码为 `2`。
- `#incloud` 失败（`E05xx`）同样输出合法 JSON，退出码为 `1`。

`--stdin` 时从标准输入读取源码，位置参数仅用作诊断里的显示名（默认 `<stdin>`）。
编辑器据此可以在文件未保存时获得实时诊断。

## 6. 引入（#incloud）

`#incloud` 把外部代码或能力接进当前程序。它在词法之前由加载器处理，之后仍是
**一份源码**走完整条流水线——语法、静态检查、求值都不知道多文件的存在。

### 6.1 两种目标

| 写法 | 目标 | 效果 |
| --- | --- | --- |
| `#incloud web` | 内置能力模块 | 该模块的函数直接可用；不产生任何源码 |
| `#incloud 工具` / `#incloud 工具.lemon1` | `.lemon1` 源文件 | 该文件的源码并入本程序 |

解析顺序：

1. 以 `.lemon1` 结尾 → 一律按**源文件**解析（相对当前文件所在目录）。
2. 否则先查**内置能力模块**表。
3. 没命中模块、而且名字带扩展名（`package.json`）→ `E0502`：只支持 `.lemon1` 源文件。
4. 否则按 `<名字>.lemon1` 找**源文件**；找不到报 `E0501`，并列出同目录的 `.lemon1` 候选
   （与写错的名字相近的排在前面）。

模块优先于同名文件：同目录即使有 `web.lemon1`，`#incloud web` 拿到的仍是模块；
要引那个文件就写成 `#incloud web.lemon1`。

### 6.2 并入的位置

- 写在 `__init__` **之前**：内容落到 `__init__ {` 之后——这是最常见的写法。
- 写在 `__init__` **之内**：就地展开。

被并入的文件是"零件"：**只写 `def` 与变量**，不要再写 `__init__` / `main()`
（写了报 `E0504`）。它本身不是一个可运行的程序，单独 `lemon run` 会因缺少 `__init__`
报 `E0301`。

同一个文件**只并入一次**：A 引 B、B 引 C、A 又引 C 时 C 只出现一次（菱形依赖是常态）。
互相引入不会绕不出来；引入层数上限 32 层，超过报 `E0503`。

### 6.3 错误定位

缝合后的每一行都记着它来自哪个文件的哪一行。因此被引入文件里的错误，报错指向
**那个文件**的行号与代码片段，而不是入口文件里 `#incloud` 那一行：

```
错误[E0307] int（整数）与text（文本）不能用 '+' 运算
  --> lib/工具.lemon1:3:9
  |
3 |     say(结果 + "不是数字")
  |         ^^^^^^^^^
  = 提示：数字与文本不能直接相加；文本只能与文本用 '+' 拼接
```

### 6.4 能力模块

模块是一批内置函数的命名集合。启用后其中的函数与 `say` / `sleep` 完全同级：
同样的静态检查（参数个数、参数类型）、同样的运行期错误，同名冲突也走同一条规则。

| 模块 | 说明 | 提供的函数 |
| --- | --- | --- |
| `web` | 网页能力：打开浏览器、抓取网页正文 | `openUrl(网址)` → `unit`；`fetchText(网址)` → `text` |

没写 `#incloud` 就调用模块函数，静态检查报 `E0308`，并提示它来自哪个模块、要补哪一行。
启用同一个模块多次是幂等的。

`openUrl` / `fetchText` 只接受 `http://` / `https://` 开头的网址（否则 `E0321`）。
`fetchText` 超时 15 秒、正文上限 4 MB，失败报 `E0414`，实现上依赖系统里的 `curl`；
`openUrl` 失败报 `E0413`。两者都是普通运行期错误，可以被 `try` / `catch` 捕获。

**注意**：网址里的 `:` 不是 Lemon 的语法符号，必须写成字符串字面量——
`openUrl("https://example.com")`。

### 6.5 websets()：用网页描述界面

`#incloud web` 除了给出 `openUrl` / `fetchText`，还解锁一个语言构造：`websets()`。

```lemon
#incloud web

__init__ {
    text 本地服务 = "localhost:9000"

    main() {
        say("逻辑照常跑在终端")
    }

    websets() {
        web.init() {
            button {
                to 本地服务               // 可以引用变量
            }
            button {
                to "https://example.com"
            }
            div (in (0,0;256,256); color=#ffffff) {   // 位置盒子 + 背景色
                你好
                div (in (8,8;100,40)) { 内层 }         // 嵌 div，坐标相对父容器
                button { to "https://example.com/inside" }
            }
        }
    }
}
```

- `websets()` 与 `main()` **同级**（`__init__` 顶层）：不写 `def`、不能带参数、**至多一个**、
  可以完全不写（那就是纯终端程序）。写在函数体或分支里报 `E0201`。
- 由 `#incloud web` 解锁；没启用时报 `E0323`，提示补 `#incloud web`。
- `web.init()` 是**页面根容器**，元素都写在它里面；缺了报 `E0324`，只能有一个。
- 元素有三种：`button`、`div`、以及**文本内容**（直接写一条表达式：裸文本 / 字符串 / 变量）。
  名字后面直接跟 `{` 却既不是 `button` 也不是 `div` 时，报 `E0325`。
- `button` 需要一个 `to <地址>`（缺了报 `E0324`）；地址必须是 `text`，可以是字面量或变量
  （否则报 `E0307`）。
- `div` 可以带一个**属性括号**（可整个省略），属性用 `;` 分隔、只能有 `in(...)` 与 `color=...`：
  - `in (x1,y1;x2,y2)`：**位置盒子**，两点是左上与右下（单位 px）；四个坐标都必须是**数字**
    （`int` / `double`，可以是字面量或变量），否则报 `E0307`。没写 `in` 的 div 按普通块级容器排布。
  - `color=<颜色>`：**背景色**，值必须是 `text`，通常直接写颜色字面量 `#rrggbb` / `#rgb`。
    颜色字面量在词法层解析成文本（值为原样的 `#...`），所以也能 `say(#ffffff)` 或存进 `text` 变量。
  - 属性名不认识、重复、或漏了 `;` 分隔，都报 `E0348`。
- `div` 里的子元素可以是文本、嵌套 `div`、`button`；嵌套 div 的 `in` 坐标**相对父容器**。
- 它是**声明**不是执行：不参与 `__init__` 顶层语句的顺序，也不产生终端输出。

**产出**：`__init__` 顶层语句与 `main()` 都跑完之后，Lemon 按这份描述求出页面，
写成与入口同名的 `.html`（`app.lemon1` → `app.html`，同目录），然后用系统默认浏览器打开。
`--no-open` 可以只落盘不开浏览器（脚本与 CI 用）。页面是**自包含**的：样式内联、不引用外部资源。

地址会被规范化写入 `href`：不带协议的一律补 `http://`。**`localhost:9000` 必须补**——
它在 URI 语法里是合法的（scheme 叫 `localhost`），浏览器会把它当协议，点了没有任何反应。
`to "localhost:9000"` → `http://localhost:9000`；`to "https://x"` 原样保留。

页面写不出去（磁盘只读、路径不可写）不算运行失败：`main()` 的输出已经完成，退出码仍是 `0`，
只在 stderr 报一句提示。

### 6.6 game()：声明一个游戏窗口

`#incloud game` 解锁一个语言构造：`game()`。它声明式地描述一个游戏窗口，形状与
`websets()` 完全一致。

```lemon
#incloud game

__init__ {
    game() {
        game.init() {
            display.win(1000, 800)     // 窗口画布尺寸（int × int）
            display.head("lemon")      // 窗口标题（text）
        }
    }

    main() {
        game.running = true            // 运行状态（bool）
        if game.quit == true {
            game.running = false
        }
    }
}
```

- `game()` 与 `main()` **同级**（`__init__` 顶层）：不写 `def`、不能带参数、**至多一个**。
  写在函数体或分支里报 `E0201`。
- 由 `#incloud game` 解锁；没启用时报 `E0335`，提示补 `#incloud game`。
- `game.init()` 是**窗口根容器**；缺了报 `E0336`，只能有一个。
- `display.win(宽, 高)`：宽高必须是 `int`（否则 `E0307`）；缺省 800×600。
- `display.head(标题)`：标题必须是 `text`（否则 `E0307`）；可引用变量；缺省标题 `Lemon Game`。
- `game.init` 里出现别的元素报 `E0337`。

**运行状态**：`game.running` 与 `game.quit` 是两个内置 `bool`，位于 `game` 命名空间下
（只能取这两个字段，取别的报 `E0317`）。**赋值语句** `game.running = <bool表达式>` 是
Lemon 唯一允许的"重新赋值"——它只对 game 的运行状态开口子；给普通变量或别的对象赋值
仍按原规则报错（`E0338` / `E0201`）。赋的值必须是 `bool`（否则 `E0307`）。

**产出**：`__init__` 顶层语句与 `main()` 都跑完之后，Lemon 按这份描述求出窗口，写成
`<入口名>.game.html`（`app.lemon1` → `app.game.html`，同目录），再按需用系统默认浏览器
打开（`--no-open` 只落盘）。页面**自包含**：一块 `宽×高` 的 `<canvas>`，外面套一层带标题栏的
"窗口"。写不出去不算运行失败，退出码仍为 `0`。

### 6.7 class：字段 + 方法的封装

`#incloud class` 解锁 `class` 构造：把若干字段与行为打包成一个“类”，用类名构造对象。
**没有构造函数**——`类名(实参...)` 按字段书写顺序把实参打包进去。

```lemon
#incloud class

__init__ {
    class Student {
        text name                  // 字段：类型 + 名字（无初始值）
        int age

        def name1(self) {          // 方法：第一个参数是接收者，约定叫 self
            return self.name + "1"
        }

        def name2(self) {
            return self.name + "2"
        }
    }

    main() {
        Student stu = Student("小明", 18)   // 用类名当类型声明变量
        say(stu.name)                        // 读字段
        say(stu.age)
        text a = stu.name1()                 // 调方法（不用给 self）
        text b = stu.name2()
        say(a + b)                           // 小明1小明2
    }
}
```

- `class` 与 `main()` **同级**（`__init__` 顶层）：至多一个名字一个类，写在函数体里报 `E0201`。
  由 `#incloud class` 解锁，没启用报 `E0339`。
- **字段**：`类型 名字`（类型限 `int`/`double`/`text`/`bool`）。顺序决定构造实参的顺序；
  重名报 `E0306`。
- **方法**：`def 名字(self, 参数...) { ... }`，可带 `return`。第一个参数是**接收者**，
  调用时自动绑定到对象（写 `self` 只是惯例，叫什么名字都行）。
- **构造**：`类名(实参...)`，个数必须等于字段数（否则 `E0310`），类型要能赋给对应字段（否则 `E0307`）。
- **访问**：`对象.字段` 读字段；`对象.方法(实参...)` 调方法；方法内可用 `self.字段` / `self.其它方法(...)`。
  不存在的字段/方法报 `E0317`。
- 对象是**只读**的：没有字段赋值（`对象.字段 = ...` 报 `E0338`），字段值也不可变。
- 类里写了字段/方法之外的东西报 `E0341`。

### 6.8 fileskill：进目录、运行文件、删文件

⚠️ **这是语言里最危险的能力**：它会**真删文件**、**真运行程序**。只在可信的代码里用
`#incloud fileskill`。

```lemon
#incloud fileskill

__init__ {
    main() {
        cd "e:/traingame" {           // 锁定在这个文件夹
            running "start.bat"       // 运行该文件夹里的 start.bat
        }
        cd "C:/Users/Administrator/Desktop" {
            delete "新建文本文档.txt"    // 删除该文件
        }
    }
}
```

三条语句：

- `cd <目录> { ... }`：锁定一个目录，**块内**的 `running` / `delete` 都以它为基准。
  目录必须是文本；不存在或不是文件夹报 `E0417`。允许嵌套。
- `running <文件>`：在当前 `cd` 目录里运行一个文件（Windows 上 `.bat` / `.cmd` 经 `cmd /c`，
  其它类型直接执行）。子进程的 stdout / stderr 原样转发；退出码非 0 报 `E0418`
  （可用 `try / catch` 兜住）。
- `delete <文件>`：删除当前 `cd` 目录里的一个文件。**只删文件，不删文件夹、不递归**
  （目标是目录报 `E0419`）。

安全边界（都是刻意的保护，不是缺陷）：

- `running` / `delete` **只能写在 `cd { ... }` 里**，写在别处报 `E0346`。
- 目标必须**落在 `cd` 目录内**：写 `..` 或绝对路径想逃出去，报 `E0420`，且文件不会被改动。
- 目录 / 文件名必须是文本；裸文本里的 `\`、`:`、`.` 会被拆开，所以**要加引号**。
- **Windows 路径在字符串里要用 `/` 或 `\\`**：`"e:\traingame"` 里的 `\t` 是制表符转义，
  正确写法是 `"e:/traingame"` 或 `"e:\\traingame"`。

### 6.9 上下文关键字

`websets` / `web.init` / `button` / `to` / `div` / `in` / `color` 都**不是全局关键字**，只在上面那几个位置有特殊含义：

```lemon
__init__ {
    int button = 1
    int to = 2
    int websets = 3

    main() {
        say(button + to + websets)   // 6 —— 全是普通变量
        say(button)                  // button —— 仍是裸文本
    }
}
```

这样新增构造不会破坏既有程序。代价是元素名不能靠词法表扩展——加新元素只需在
解析器里加一个分支（见 `parseWebElement`）。

## 8. 演进方向

以下能力**明确不在 v0.2.0 范围内**，语言内核的分层设计已为其预留位置：

| 版本 | 内容 |
| --- | --- |
| v0.1 | `__init__` / `main` 外壳、`int` / `double` / `text`、裸文本、`def`、`say`、`try` / `catch` |
| v0.2 | 四则运算 `+ - * /`、乘方 `**`、一元正负号、文本拼接；`bool` 类型、比较 `== != < <= > >=`、逻辑 `&& \|\| !`（短路）；`if` / `elif` / `else`；`cycle(N)` / `cycle()` 循环与 `break` |
| v0.3 | 键盘输入 `keyboard(键)` / `waitKey(键)`（含键名静态校验与 Ctrl+C 中断） |
| v0.4 | 时间单位字面量（`500ms` / `2s` / `1min` / `1h`）与 `sleep`；`#incloud` 引入 `.lemon1` 源文件与内置能力模块（`web`：`openUrl` / `fetchText`）；`websets()` 网页界面（`web.init` + `button`，生成自包含 `.html`） |
