# LemonMod 教程（v0.2）

一篇面向初学者的上手教程。你只需要知道：LemonMod 的程序写在 `.lemon2` 文件里，跑起来会一行一行地输出结果。

先编译再运行（一次即可，之后改了源码要重跑）：

```bash
npm run mod:build
```

下面每个例子都是一份完整可运行的 `.lemon2` 文件。

---

## 1. Hello, LemonMod

每个文件都有固定外壳：`set 文件名 public {` 包住一个 `class public { ... }` 初始化块。

```lemon2
set hello public{
    class public{
        say(hello)
        printf("hello")
    }
}
```

运行：

```bash
node mod/bin/lemonmod.js hello.lemon2
```

输出：

```
hello
hello
```

要点：
- `set hello public { ... }` 是文件外壳，`hello` 是文件名（随便取，可含汉字）。
- `class public { ... }` 是"初始化块"，里面写要执行的语句。
- `say(hello)` 和 `printf("hello")` 都能输出一行；前者吃裸文本，后者吃字符串，结果完全一样。

---

## 2. 变量：免声明、可重复赋值

v0.2 引入了变量。**不需要写类型**，直接 `名字 = 值`：

```lemon2
set var public{
    class public{
        a = 1
        say(a)          // 1
        a = 5
        say(a)          // 5（重复赋值）
        x = 你好
        say(x)          // 你好
    }
}
```

要点：
- 变量**动态类型**：数字和文本都能装，不需要 `int` / `text` 这类声明。
- 可以反复赋值，最后一次生效。
- 赋值语句和 `say`/`printf` 可以随意混排。

---

## 3. 表达式与四则运算

`=` 右边、`say` / `printf` 括号里都能放表达式。

```lemon2
set calc public{
    class public{
        a = 2
        b = 3
        say(a * b)          // 6
        say(1 + 2 * 3)      // 7（* 优先于 +）
        say((1 + 2) * 3)    // 9（括号提优先级）
        say(10 / 4)         // 2.5
        say(7 - 2 - 1)      // 4（左结合）
        c = -3
        say(c)              // -3（一元负号）
        pi = 3.14
        say(pi)             // 3.14（小数）
    }
}
```

运算规则：
- `+ - * /` 和括号；`*` `/` 优先于 `+` `-`，同级从左到右。
- 一元 `+` / `-`：`-3`、`-(a + b)`；`+` 是数值恒等。
- 只有数字能参与 `- * /`，否则运行期报类型错误。

---

## 4. 文本拼接

`+` 很特殊：只要**任一侧是文本**，就做拼接（数字也会被转成文本）。

```lemon2
set concat public{
    class public{
        say(你好 + 世界)        // 你好世界
        a = 1
        say(a + 倍)             // 1倍
        say(分数 + 90)          // 分数90
    }
}
```

注意：`-` `*` `/` 不支持文本，下面这样会报错（`M04xx` 类型不匹配）：

```lemon2
x = 你好
say(x - x)       // 错误：文本不能做减法
```

## 5. 未定义的裸词 = 文本

这是一个刻意的兼容设计：**没赋过值的裸词，会当成它的名字本身当文本输出**。

```lemon2
set fallback public{
    class public{
        say(hello)      // hello（hello 从没赋值，回退成文本）
        say(柠檬)        // 柠檬
    }
}
```

好处：`say(柠檬)` 永远能输出「柠檬」二字，不必先定义变量。
代价：拼错变量名不会报错，而是悄悄输出那个名字。若你更想要"未定义即报错"，需要改 `src/interpreter.ts` 的变量查找逻辑（见教程结尾的练习）。

---

## 6. 断句与注释

- 语句之间用**换行**或**分号**分隔，可混用。
- 同行写多条语句必须用 `;`。
- `//` 到行尾是注释。

```lemon2
set sep public{
    class public{
        say(a); say(b)      // 同行两条，用分号
        say(c);
        // 下面一行是注释
        x = 1
        say(x)              // 1
    }
}
```

## 7. 看看错误长什么样

故意写错，体会诊断信息（走 stderr，带位置）：

```lemon2
set err public{
    class public{
        say()               // 缺参数
    }
}
```

```
err.lemon2:3:9: error M0203: `say` 需要 1 个参数：数字、变量、字符串或裸文本（如 say(hello)）
    3 |         say()
      |         ^
```

其它常见错误：`say(a, b)`（参数过多 `M0205`）、`foo(1)`（未知语句 `M0201`）、`printf("hi)`（字符串未闭合 `M0301`）、`say(1/0)`（除零 `M04xx`）。

## 9. 条件分支 if / elif / else

光有变量还不够，判断靠 `if`。条件是一个表达式，按**真值**判定：数字非零为真、文本非空为真、布尔值本身为真。

```lemon2
set branch public{
    class public{
        a = 1
        if a == 1 {
            say(相等)
        } else {
            say(不等)
        }
    }
}
```

输出 `相等`。

**比较运算**产生布尔：`== != < <= > >=`。

```lemon2
set cmp public{
    class public{
        say(3 > 2)        // true
        say(1 >= 2)       // false
        say(你好 == 你好)  // true
        say(!(1 == 2))    // true（! 逻辑非）
    }
}
```

**elif / else** 写多分支：

```lemon2
set grade public{
    class public{
        分 = 85
        if 分 >= 90 {
            say(优秀)
        } elif 分 >= 60 {
            say(及格)
        } else {
            say(不及格)
        }
    }
}
```

输出 `及格`。

要点：
- `if 条件 { }` 后可选接任意多个 `elif 条件 { }`，最后可选接一个 `else { }`。
- 分支按顺序判定，**第一个为真**的分支执行，其余跳过。
- `elif` / `else` 只能出现在 `if` 之后，写在最外层会报错。
- 关系运算 `< <= > >=` 只接受数字；文本之间只能比 `==` / `!=`。
- 分支里可以再写 `if`（嵌套），也可以写赋值与 `say`/`printf`，混排无限制。
