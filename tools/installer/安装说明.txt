Lemon 安装说明
======================================================================

这个文件夹里有四个文件，一个都不能少：

    lemon.exe             解释器本体（自带运行时，目标电脑不需要装 Node）
    lemon-language.vsix   编辑器扩展（语法高亮、实时诊断、运行按钮）
    install.ps1           安装脚本（真正干活的）
    安装.bat              双击这个就行

安装
----------------------------------------------------------------------

把整个文件夹复制到目标电脑（用 UU 远程直接传文件夹即可），
然后双击 "安装.bat"。

脚本会做四件事，全部只影响当前用户，不需要管理员权限：

    1. 把 lemon.exe 放到 %LOCALAPPDATA%\Programs\Lemon\
    2. 把这个目录加进「用户 PATH」（不会碰系统 PATH）
    3. 自动找到编辑器的命令行入口，装上 lemon-language.vsix
    4. 把解释器路径写进编辑器设置 lemon.executablePath

装完必须做两件事
----------------------------------------------------------------------

1) 重启编辑器
   语言注册、扩展、文件图标都是启动时读一次。不重启不会生效。

2) 新开一个终端窗口
   已经开着的窗口读的是旧 PATH。然后验证：

       lemon --version
       lemon examples\hello.lemon1

   编辑器里打开任意 .lemon1 文件，右上角会出现「▶ 运行」按钮，
   编辑时下方会自动出现波浪线诊断。

如果第 3 步失败（脚本会明确提示）
----------------------------------------------------------------------

说明脚本没找到编辑器的命令行入口。手动装，一次就够：

    1) 打开编辑器 → 左侧「扩展」面板
    2) 点面板右上角的「...」→「从 VSIX 安装...」
    3) 选中本文件夹里的 lemon-language.vsix
    4) 重启编辑器

扩展找不到解释器时，也可以在编辑器设置里手动填：

    "lemon.executablePath": "C:\\Users\\你的用户名\\AppData\\Local\\Programs\\Lemon\\lemon.exe"

怎么卸载
----------------------------------------------------------------------

    1) 编辑器扩展面板里卸载「Lemon Language」
    2) 删掉文件夹 %LOCALAPPDATA%\Programs\Lemon
    3) 在「系统属性 → 环境变量」的用户变量 Path 里删掉那一项

需要管理员吗？
----------------------------------------------------------------------

不需要。脚本只写两个位置：

    %LOCALAPPDATA%\Programs\Lemon\      解释器
    HKCU\Environment 的 Path            用户级 PATH

以及编辑器自己的配置目录 %APPDATA%。都不需要提权。
